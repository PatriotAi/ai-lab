# AGENTS.md — для агентів, що не читають CLAUDE.md

Канон правил цього репозиторію — `CLAUDE.md`. Тут лише вказівник і короткий перелік
інваріантів для рев'ю. За розбіжності правий `CLAUDE.md`; правила тут не дублюються.

Мова лабораторії — українська: пиши зауваження українською.

## Code Review Rules

1. **Доказовість (`CLAUDE.md` §10).** Тег `[E]` — лише з вказівником, який існує в репозиторії
   або відтворюється командою. Твердження, яке з репозиторію не перевірити (журнал сесії,
   архів поза репо, недоступна сторінка), має бути `[C]`. Познач `[E]` без такого доказу.
2. **Актуальність (`CLAUDE.md` §7).** Версії, лічильники й дати в документах мусять дорівнювати
   факту в тому ж коміті. Похідне рахує `melania-skills-ecosystem/scripts/maintain.py resync`,
   розбіжність ловить `maintain.py verify`. Познач число чи дату, що відстали від змін у PR.
3. **Зміна навички Melania (`CLAUDE.md` §4).** Кожна змінена `SKILL.md`: bump версії, H1 і
   `last_updated` синхронні, один запис у «Зміни», рядок у `melania-skills-ecosystem/MELANIA-BOOTSTRAP.md`.
4. **Безпека (`SECURITY.md`).** Жодних секретів у коді — лише env-змінні. Дії GitHub
   закріплюються повним SHA коміта, не тегом (`scripts/check-action-pinning.sh`).
