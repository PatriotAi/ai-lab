КРОКИ — п'ять ходів, незалежні виклики в одному ході паралельно (OUT = тека-чернетка з твого системного промпту, а якщо її немає — поточна робоча тека; T = `$(git rev-parse --show-toplevel)` — твій репозиторій ai-lab)
1. `list_repos` → усі репо, крім `fork: true` (нові репо так підхоплюються самі). Якщо в T немає `automations/repo-monitor/run.sh` — зупинись і скажи: дім створив сесію без source_url.
2. Одним ходом паралельно: `add_repo` (owner, repo, access: "read") для кожного з них + `Artifact` action "read" url сторінки БЕЗ path (лише право на публікацію; HTML не переписуй) + `Artifact` action "read" url сторінки з path "index.html" (збереже у файл — PAGE). Відмову `add_repo` не повторюй: публічні репо клонуються й без підключення.
3. Один Bash: `bash $T/automations/repo-monitor/run.sh $OUT <PAGE> PatriotAi <усі репо з кроку 1 через пробіл>` — клон, скан, CI/PR, сторінка; на stdout — дельта. Стан сторінки ніколи не набирай вручну. Для публічних репо без підключення CI-стан не читається (`gh api` 403) — відома межа: у звіті одним рядком, не як збій.
4. Одним ходом паралельно: `Artifact` publish (file_path `$OUT/repo-monitor.html`, url сторінки, без icon) + `ArtifactComments` action "watch", url сторінки, on: false. Відмова через новішу версію → один раз повтори кроки 2 (лише читання) і 3, потім опублікуй.
5. Звіт (нижче); для НОВОГО червоного CI — спершу агент діагностики (див. МОДЕЛІ).
