# automations/g5-consolidate

**Одна відповідальність:** авто-консолідація стану пам'яті на межі сесії (Stop-хук) —
крок до G5 ✅ у серії GMI (`experiments/gmi-g5-auto`).

- **Тригер:** `Stop` (реєстрація в `.claude/settings.json`).
- **Дія:** `g5-consolidate.sh` → `scripts/g5-consolidate.py experiments/gmi-g5-auto`
  → регенерує `AUTO-STATE.md` з git (HEAD, гілка, коміти, файли).
- **Властивості:** детерміновано, **без AI/мережі/секретів**, ніколи не блокує Stop (`|| true`).
  `AUTO-STATE.md` — гітігноровано (регенерується, тримає дерево чистим).

Прибирає ручний крок консолідації пам'яті. Кандидат на узагальнення (будь-яка тека) — крок 5.
