# automations/ — хуки, скрипти, пайплайни

Версіонований source автоматизацій, які виконуються **без участі людини** або
на події: хуки (`SessionStart`, `Stop`…), скрипти, багатокрокові пайплайни.

## Типи
- **Хуки** — реагують на події життєвого циклу сесії. Активуються через `settings.json`.
- **Скрипти** — допоміжні утиліти (bash/python).
- **Пайплайни** — ланцюжки кроків (напр. дослідження → переклад → публікація).

## Правила
- **Одна автоматизація — одна відповідальність.** Без дублів.
- Кожна — з коротким README: що робить, на що реагує, як вимкнути.
- Без секретів у коді (див. `../SECURITY.md`).

## Примітка про платформні хуки
У `~/.claude` уже є інфраструктурні хуки середовища
(`session-start-git-identity`, `stop-hook-git-check`, `stop-hook-reply-gate`) —
це **не** наші автоматизації, їх не чіпаємо. Наші — тут і під git.
