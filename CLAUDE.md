# CLAUDE.md — контекст лабораторії

Це особиста **лабораторія продуктивності** (ai-lab). Працюємо з багатомовними
(UA/EN) проєктами та AI-автоматизаціями. Мета — створювати, покращувати,
спрощувати й винаходити робочі процеси.

## Мова
- Спілкування з користувачем — **українською**.
- Документи — українською (ключові терміни дублюй англійською).
- Артефакти для публікації — двомовні UA/EN, якщо не вказано інше.

## Структура репозиторію
- `docs/` — методологія, дорожня карта (roadmap), журнал висновків (learnings), глосарій
- `skills/` — навички (каталог-джерело; активна навичка живе в `.claude/skills/<name>/SKILL.md`)
- `automations/` — хуки/скрипти/пайплайни (джерело; активуються через `.claude`/settings)
- `experiments/` — експерименти (кожен: тека з README + входи/виходи/висновок)
- `templates/` — шаблони

## Методологія
Експеримент-орієнтована: **гіпотеза → дизайн → запуск → вимір → лиши/прибери → висновок**.
Деталі — `docs/methodology.md`.

## Конвенції
- Кожна нова навичка/автоматизація = окрема тека з коротким README/SKILL.md.
- **Одна автоматизація — одна відповідальність.**
- **Жодних секретів у репозиторії** — токени лише через env-змінні.
- Перед великими/незворотними змінами — спершу план (plan mode).
- Що лишаємо після експерименту — виносимо в багаторазову навичку/автоматизацію
  і записуємо висновок у `docs/learnings.md`.

## Доступні інструменти (MCP)
- **GitHub** — код, PR, issues
- **Vercel** — деплой/прев'ю
- **Canva** — генерація дизайн-ассетів

Скоуп інструментів і гілка розробки можуть змінюватися — звіряйся з поточною сесією.
