# publish — публікація артефакту / publish pipeline

## Призначення
Перетворює готовий текст на публікаційні асети: дизайн-картку через Canva MCP
і живе прев'ю через Vercel MCP. Останній крок після `content-pipeline`.

## Коли застосовувати
- «Опублікуй», «зроби Canva-картку», «задеплой прев'ю», «publish».
- Є готовий (вичитаний) текст — двомовний або одномовний.

## Кроки
1. **Вхід:** готовий артефакт (після `content-pipeline` або від користувача).
   Чернетки не публікуємо — спершу рев'ю.
2. Підготуй **витяг для картки**: заголовок, 2–3 тези, мова за призначенням
   (UA, EN або обидві).
3. **Canva MCP:** згенеруй дизайн-картку з витягу; за потреби — експорт PNG.
4. **Vercel MCP:** задеплой прев'ю-сторінку з артефактом (статичний HTML).
5. ⚠️ **Перед будь-яким зовнішнім деплоєм/публікацією — підтвердження
   користувача** (зовнішній сервіс може кешувати/індексувати контент).
6. Поверни посилання (Canva-дизайн + Vercel-прев'ю) і зафіксуй їх у артефакті
   чи журналі експерименту.

## Приклади
- «Опублікуй огляд як картку + прев'ю» → Canva-картка з тезами + Vercel-URL.
- «Зроби EN-картку для поста» → витяг EN → Canva → лінк.

## Нотатки
- Мінімальні скоупи MCP; прев'ю ≠ продакшн.
- Жодних секретів / PII в асетах і прев'ю.
- Якщо конектор недоступний — зроби локальний асет (HTML/MD) і познач крок
  публікації як відкладений.
