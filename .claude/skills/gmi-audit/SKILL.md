# gmi-audit — аудит когнітивної системи крізь лінзу GMI

## Призначення
Оцінює будь-яку **AI/когнітивну систему** (агента, промпт-архітектуру, cognitive
architecture, власний System Core) на **повноту інваріантів інтелекту** та
**принципи ефективності**, і повертає карту «реалізовано / прогалина» з дієвими
покращеннями. Похідне від експерименту `experiments/gmi/`.

## Коли застосовувати
- «GMI-аудит», «проаудить систему по GMI», «яких інваріантів бракує».
- Оцінити когнітивну архітектуру / агента / промпт-систему перед розвитком.
- Порівняти дві системи за спільним кістяком інтелекту.

## Лінза GMI (три осі)

### Вісь 1 — 7 динамічних інваріантів (течії, не модулі)
| G | Інваріант | Питання аудиту |
|---|---|---|
| G1 | Модель світу | Чи є *передбачувальна* внутрішня модель (а не лише каталог знань)? |
| G2 | Ціль / цінність | Чи є вектор цінності, що спрямовує поведінку? |
| G3 | Висновок / планування | Чи є пошук/інференс над моделлю (не лише реактивність)? |
| G4 | Пам'ять як атрактор | Чи є стиснення+індексація+витяг (авто, не ручний)? |
| G5 | Навчання = мінімізація похибки | Чи оновлюється система від зворотного зв'язку **між сесіями**? |
| G6 | Метакогніція | Чи є самомоніторинг/самокорекція? |
| G7 | Детермінація / read-out | Чи є явний коміт «невизначене → визначений результат»? |

> **«Генеральність» — не інваріант, а цільова властивість**, що виникає, коли G1–G7
> стають домен-інваріантними. Перевіряй перенос між доменами як тест на «general».

### Вісь 2 — стек ефективності (для питань «чому/наскільки ощадно»)
P1 пам'ять+обчислення разом · P2 розріджена подієвість · P3 аналог/низька точність ·
P4 паралельність · P5 «лише несподіванка» (predictive) · P6 критичність · P7 фізика-native.
*(P8 квантова когерентність — [S], не спирати.)* Питання: **скільки P реалізує система і якою ціною?**

### Вісь 3 — вісь спостерігача (детермінація)
Патерн **невизначене → (read-out) → визначене** на 3 рівнях (квант RQM / когніція
drift-diffusion / інфо Wheeler). «Спостерігач» ≠ конче свідомість (RQM). Перевіряй: чи має
система операцію **коміту** розподілу-гіпотез у результат (поріг/атрактор/вибір)?

## Кроки аудиту
1. Признач **об'єкт** (агент / промпт / архітектура / система).
2. Пройди G1–G7: для кожного — **реалізовано / частково / прогалина** + де саме в системі.
3. Оціни осі 2–3 за релевантністю (ефективність, наявність read-out).
4. Сформуй **карту прогалин → покращення** з пріоритетами.
5. **Кожне твердження тегуй [E]/[C]/[S]**; невизначене лишай як UNKNOWN (не вигадуй).
6. За потреби делегуй: звірку — `validation-mesh`; неочевидні зв'язки — `knowledge-synthesizer`.

## Формат виводу
```
GMI-АУДИТ: <об'єкт>
Інваріанти:   G1 ✅ · G2 🟡 · G3 ✅ · G4 ✅ · G5 🔴 · G6 ✅ · G7 🟡   (+ де/чому)
Генеральність: <перенос між доменами: є/ні>
Ефективність:  <які P реалізує; вузьке місце>
Read-out:      <є явний коміт? де>
Прогалини→дія: <пріоритезований список>
Теги:          кожен пункт [E]/[C]/[S]
```

## Приклади
- «Проаудить мій System Core по GMI» → карта G1–G7 + прогалини (напр. G5 навчання між сесіями).
- «Порівняй двох агентів за GMI» → дві карти + де кожен сильніший.

## G5-проба (навчання між сесіями)
Для G5 застосуй **cold-start recovery gate** (`continuation-memory`): зовнішня пам'ять із
**self-contained critical refs** (критичні URL/шляхи inline) + **recovery-checklist ДО тесту**.
Оцінка: **🔴** нема відновлення · **🟡** зовнішній цикл, ручний · **✅** авто-цикл
(консолідація на Stop + витяг на SessionStart — `automations/g5-consolidate` + `g5-retrieve`).

## G7-проба (детермінація / read-out)
Чи є **повний commit-протокол — усі 5 кроків** `experiments/gmi/g7-commit-protocol.md`:
кандидати → критерій (атрактор/Оккам/голос) → commit → **RESIDUAL** (залишкова невизначеність) →
**TRACE** (журнал рішення)? Оцінка: **🔴** нема (лише реактивність) · **🟡** є commit, але
**бракує RESIDUAL або TRACE** · **✅** усі 5 кроків, **включно з журналом рішення (TRACE)**.
*(Патерн G7 «невизначене→визначене»; «спостерігач» ≠ конче свідомість — RQM. Без TRACE ✅ не ставимо.)*

## Нотатки
- Лінза — **описова**, не оракул: не проголошуй систему «інтелектом», давай карту.
- Не спирай висновки на [S] (квант/вихор — метафора кореляції, не буквальність).
- Джерело методу і фактчек: `experiments/gmi/` (invariants.md, sources.md).
- Жодних секретів/PII у звіті аудиту.
