# skill-new — фабрика навичок / skill factory

## Призначення
Швидко й консистентно створює нову навичку Claude Code за конвенціями ai-lab.

## Коли застосовувати
- Користувач просить створити/додати навичку.
- Повторюване завдання варто оформити як багаторазову навичку.

## Кроки
1. З'ясуй три речі: **назву** (kebab-case, EN), **мету** (1 речення),
   **тригер** (коли застосовувати — від нього залежить авто-виклик).
2. Створи `.claude/skills/<name>/SKILL.md` за шаблоном `templates/skill.md`:
   - frontmatter `name` + `description` (description = чіткий тригер);
   - розділи: Призначення, Коли застосовувати, Кроки, Приклади, Нотатки.
3. Документи — **UA-канон**; ключові терміни дублюй EN.
4. Якщо навичка варта каталогізації — згадай її в `skills/README.md`.
5. Запропонуй маленький тест: один реальний вхід → очікуваний результат.
6. Якщо це експеримент — заведи теку в `experiments/` і зафіксуй висновок у `docs/learnings.md`.

## Приклади
- «Створи навичку для двомовного перекладу» → `.claude/skills/translate-uaen/SKILL.md`
  з тригером на запити перекладу UA⇄EN.

## Нотатки
- Одна навичка — одна відповідальність.
- Жодних секретів у тілі навички (лише env).
- Тримай `description` конкретним: розмитий опис → навичку не викличуть або викличуть не до місця.
