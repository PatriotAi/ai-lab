# translate-uaen — двомовна локалізація / UA⇄EN localization

## Призначення
Перекладає й локалізує текст між українською та англійською, тримаючи єдину
термінологію за глосарієм лабораторії (`docs/glossary.md`).

## Коли застосовувати
- Запит перекласти текст UA→EN або EN→UA.
- Зробити документ/артефакт двомовним (паралельні версії).
- Вирівняти термінологію між мовами.

## Кроки
1. Визнач напрям (UA→EN, EN→UA чи обидві версії) і тип тексту (док, UI, пост).
2. Звірся з `docs/glossary.md` — використовуй усталені відповідники; нові терміни
   додавай у глосарій (UA ⇄ EN + нотатка).
3. Перекладай за змістом, не дослівно; зберігай Markdown-розмітку, посилання, код.
4. **UA — канон.** Для двомовного артефакту: UA-секція перша, EN — дзеркалом.
5. Звір узгодженість: однаковий термін → однаковий переклад усюди.
6. Для документів репозиторію дотримуйся структури `docs/ua` + `docs/en`
   (парні файли з перемиканням) або білінгвального файлу з якорями.

## Приклади
- «Переклади README EN→UA» → UA-версія тими самими термінами, що в глосарії.
- «Зроби цей пост двомовним» → UA-блок + EN-блок, узгоджені терміни.

## Нотатки
- Зберігай тон і форматування оригіналу.
- Не вигадуй терміни — спершу глосарій; розширюй його за потреби.
- Жодних секретів/PII у прикладах перекладу.
