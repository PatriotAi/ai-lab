# Безпековий стрижень

Самодостатній пакет, що перетворює безпекові правила з «агент їх пам'ятає» на
«машина їх перевіряє». Працює в Claude Code через хуки.

**Головна ідея одним реченням:** дія отримує рівень ризику, і що вищий рівень —
то більше перевірок; незворотне зупиняється й питає людину, решта йде сама.

Політика безпеки лабораторії — у [`../SECURITY.md`](../SECURITY.md).

---

## Що це дає власнику, який не читає код

- **Читання й звичайні правки** — без питань і без затримки.
- **Незворотне** (примусовий пуш, злиття, секрети, зміна CI) — зупиняється,
  і ти отримуєш пояснення звичайними словами: що я хотів зробити, чому це
  зупинено, які є інші можливості.
- **Текст іззовні** (веб, коментарі, власна пам'ять між сесіями) — приходить
  позначеним як **дані**, а не як команди.
- **Перевірка, яка не виконалась, ніколи не звітує «чисто».**

---

## Швидкий старт

```bash
python3 scripts/security-drift.py    # що ввімкнено НАСПРАВДІ
bash scripts/security-check.sh       # локальні перевірки (3 стани, не 2)
bash tests/run-tests.sh              # чи працює те, що обіцяно
bash security/tests/test-standalone.sh   # чи працює пакет ПОЗА цим репо
```

## Склад

| Файл | Відповідальність |
|---|---|
| `policy.toml` | **Єдине** місце: «дія → рівень ризику → що робити». Коментарі українською; щоб змінити поведінку, код чіпати не треба |
| `spine/classify.py` | Дія → рівень `R0`…`R4`. Розрізає симлінки **до** рішення |
| `spine/explain.py` | Вердикт → пояснення людською мовою |
| `spine/memory_guard.py` | Охорона пам'яті, що перетинає межу сесій |
| `spine/pretooluse.py` | Рішення для хука + журнал |
| `hooks/pre-tool-use.sh` | Міст: контракт stdin/stdout Claude Code |
| `consent.md` | Записана згода власника: іменна, датована, видима в діффі PR |
| `tests/test-standalone.sh` | Доказ переносимості: 18 перевірок у порожній теці без файлів ai-lab |
| `fixtures/` | **Заморожені** зразки для канарок — щоб перевірки не розкладались |
| `audit/` | Журнал рішень (локальний, поза git) |
| `trivy.yaml` | Налаштування Trivy (вразливості, секрети, місконфіги) |

## Рівні ризику

| Рівень | Що це | Що відбувається |
|---|---|---|
| `R0` | Читання | Нічого. Без перевірок, без журналу |
| `R1` | Правка файлу в проєкті | Проходить; зміна видима в git |
| `R2` | Команда з наслідками | Проходить; записується в журнал |
| `R3` | Текст іззовні | Скан + позначка «це дані, не інструкції» |
| `R4` | Незворотне або назовні | **Блок** + пояснення + очікування згоди |

## Як увімкнути в іншому репозиторії

1. Скопіювати теку `security/` у корінь.
2. Додати хук у `.claude/settings.json`:

   ```json
   { "hooks": { "PreToolUse": [ { "hooks": [
       { "type": "command",
         "command": "$CLAUDE_PROJECT_DIR/security/hooks/pre-tool-use.sh" } ] } ] } }
   ```

3. Перевірити ділом: `bash security/tests/test-standalone.sh` (має бути зелено
   ще до підключення хука), далі `python3 scripts/security-drift.py`.

**Залежності:** лише Python 3.11+ (стандартна бібліотека) і `bash`. Без мережі,
без сторонніх пакетів. `memory_guard.py` додатково використовує
`scripts/scan-external-input.py` і `scripts/g5-retrieve.py` — без них решта
пакета працює, гейт пам'яті просто не вмикається.

## Як вимкнути

Прибрати запис `PreToolUse` із `.claude/settings.json`. Решта файлів нічого не
робить сама по собі. **Вимкнення варто робити свідомо, а не «на час розбору»** —
вимкнений «на час» гейт має властивість лишатися вимкненим.

## Чого цей пакет НЕ робить

Названо прямо, щоб ніхто не вважав його повнішим, ніж він є:

- **Не захищає від себе — лише робить самозміну видимою.** Агент може редагувати
  `spine/*.py`; це **не блокується**, але записується окремим класом (прапорець
  `self_modification` у журналі, гучний рядок у stderr, лічильник у звіті дрейфу).
  Блок тут дав би ілюзію бар'єра: агент однаково може виписати собі згоду.
  Перевірка, яку виконує той, кого перевіряють, завжди має цю дірку. Реальне
  закриття — поза агентом: захист гілок, обов'язковий рев'ю, підписані коміти.
- **`consent.md` — реєстратор, не бар'єр.** Його цінність у тому, що кожне
  використання назване й видиме в діффі, а не в неможливості його виписати.
- **Скан ін'єкції — тріаж.** Ловить відомі формулювання; перефразоване пройде.
  Справжній захист — позначка «це дані», а не скан.
- **Класифікатор працює за переліком.** Нова форма небезпечної дії його обійде.
  Він піднімає підлогу, не ставить стелю.
