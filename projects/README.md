# projects/ — самостійні проєкти-зразки

Тут зберігаються **повноцінніші напрацювання**, які допрацьовуються, оновлюються
й згодом можуть виноситися в окремі репозиторії. Мова/стек кожного проєкту
обирається індивідуально.

## Проєкти
| Проєкт | Що це | Статус |
|---|---|---|
| [`mobile-agent/`](mobile-agent/) | **Кишеньковий агент** — AI-агент прямо зі смартфона, без ПК і без сервера: один HTML на головному екрані, працює навіть офлайн | в роботі (наскрізний зріз ✅) |

## Як почати
Скопіюй [`project-template/`](project-template/) у `projects/<назва>/` і заповни.

## Чим відрізняється від `experiments/`
- `experiments/` — маленька гіпотеза, яку швидко перевіряємо й лишаємо/прибираємо.
- `projects/` — те, що вже доводимо до робочого стану й, можливо, виносимо назовні.

## Правила
- Кожен проєкт — з власним `README.md` і `.env.example` (без секретів).
- Статус позначай у README (чернетка / в роботі / готово до виносу).
