# План на потім — інші «телефони й комп'ютери напрокат»

Лише записано, **не зроблено**. Кожен пункт — окремий експеримент за методологією
лабораторії (гіпотеза → дизайн → запуск → вимір → висновок).

## 1. iOS (iPhone / iPad)
- **Як:** раннери GitHub `macos-latest` + Xcode Simulator (`xcrun simctl`): встановити
  збірку, відкрити, знімки (`simctl io screenshot`), відео (`simctl io recordVideo`),
  сайти — у Safari. Сценарії — той самий Maestro (підтримує iOS-симулятор).
- **Межа:** лише **власні** збірки для симулятора (`.app`, зібрані під симулятор).
  Готові `.ipa` з App Store на симуляторі не запускаються (шифрування, інша архітектура).
- **Ціна:** на **публічному** репозиторії стандартні раннери macOS безкоштовні, як і Linux (виправлено 2026-11-21; раніше тут помилково стояло «~10× дорожче» — це правда лише для приватних репо). Розбір — `docs/reviews/2026-11-21-simulation-toolchain.md`.

## 2. HarmonyOS (Huawei)
- **Як:** DevEco Studio емулятор; перевірити, чи є легальний безголовий (без екрана)
  запуск на Linux/Windows-раннерах і чи дозволяє ліцензія автоматизацію в хмарі.
- **Ризик:** емулятор може вимагати акаунт Huawei Developer і локальний комп'ютер —
  тоді лише вручну або на власному раннері.

## 3. Десктопні системи
- **Windows / macOS / Linux:** раннери `windows-latest`, `macos-latest`, `ubuntu-latest`
  вже є «комп'ютерами напрокат»: встановити програму, запустити, зняти знімки екрана
  (на Linux — віртуальний дисплей Xvfb), записати журнал падінь.
- **Сайти на десктопі:** Playwright (Chrome/Firefox/Safari-WebKit) — вже вміє все потрібне;
  можна додати як режим «desktop» поруч з телефоном.

## 4. Покращення поточного Android-симулятора
- Кеш знімка ввімкненого телефона (AVD snapshot) — скоротити запуск на 2–3 хв.
- Кілька пристроїв за один запуск (телефон + планшет) для порівняння.
- Перевірка ARM-only застосунків як окремий самотест.
