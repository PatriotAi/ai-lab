# Журнал висновків / Learnings

Компаундна пам'ять лабораторії. Кожен завершений експеримент лишає тут 3–5 рядків.

## Формат запису
```
## YYYY-MM-DD — <тема>
- Контекст: навіщо робили
- Що зробили: коротко
- Висновок: що дізналися (спрацювало/ні)
- Дія: лишили / прибрали / промоутнули в skills|automations
```
