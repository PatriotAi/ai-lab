## 0. Узгоджені параметри (single source of truth)
- **Назва:** GitHub `ai-lab` / укр. «ШІ-лаб»
- **Власник:** персональний акаунт PatriotAi
- **Мета:** центральне сховище для опрацювання та прототипування багатомовних проєктів з AI
- **Призначення:** зразки/шаблони → допрацювання → виніс в окремі репозиторії
- **Мови програмування:** індивідуально під проєкт (не фіксовані)
- **AI-помічники:** Claude / Claude Code, Codex, інші AI-сервіси
- **Документація:** білінгвальна, **UA-first** зі швидким перемиканням UA⇄EN
- **Безпека:** повний набір (секрети, вразливості, SAST, залежності, рев'ю)
- **Ліцензія:** ⚠️ зараз Apache-2.0; Copilot пропонував MIT — потрібне рішення (§Рішення)

### Дві теки для роботи (не плутати)
- `experiments/` — **маленькі гіпотези**, які швидко перевіряємо й лишаємо/прибираємо.
- `projects/` — **повноцінніші зразки**, які допрацьовуємо й виносимо в окремі репозиторії.

## Фаза 2 — Довершення безпеки та CI 🟡 (код ✅; branch protection — рішення «варіант C», див. висновок 2026-07-13)
1. `.github/workflows/code-quality.yml` (розширений із первинного `lint.yml`): pre-commit +
   actionlint + форматування за мовами (коли з'явиться код).
2. `.github/workflows/dependencies.yml` — `dependency-review-action` (рев'ю залежностей у PR).
   *Виправлення чернетки Copilot:* `dependabot.yml` лишається в `.github/`, **не** в `security/`.
3. `scripts/setup.sh` — бутстрап: встановити `pre-commit`, hooks, перевірити оточення.
4. `scripts/security-check.sh` — локально прогнати gitleaks + Trivy + pre-commit одним викликом.
5. `projects/project-template/` — додати `.gitignore` і `src/.gitkeep`.
6. ✔ **Branch protection** для `main` — **рішення прийнято (варіант C, 2026-07-13):** жорсткі
   GitHub rulesets не діють на приватному репо на безкоштовному плані, тож обрано **м'який
   governance** — доступ лише власника + `CLAUDE.md` без авто-злиття (merge у `main` тільки
   за явною згодою власника) + увімкнено Dependency graph. Це свідомий вибір, не блокер;
   жорсткий замок (обов'язкові PR/рев'ю/зелені перевірки) — лише за апгрейду плану (public/Team).
7. ✔ **Code/secret scanning** — той самий контекст free-плану: покрито CI-рівнем (gitleaks +
   Trivy + Semgrep у workflow, SARIF) замість вбудованого GitHub Advanced Security; активація
   вбудованого — теж за апгрейду плану.

## Фаза 5 — Дослідницька серія GMI ✅ ЗРОБЛЕНО
Знаннєвий vertical slice: `experiments/gmi/` — **Загальна Модель Інтелекту (GMI)** як
інваріантний кістяк (G1–G7) + вісь спостерігача (детермінація/read-out) + стек ефективності
(P1–P7); deep-research з тегами доказовості [E]/[C]/[S]; grounding на власний System Core;
двомовний **інтерактивний Claude Artifact**. Повний ланцюг навичок (harvest → synthesizer →
validation-mesh → content-pipeline → translate-uaen → pre-delivery-gate). **Промоутнуто:**
нова навичка `gmi-audit` (GMI-лінза) + крос-лінк у `ai-core-runtime`/`knowledge-synthesizer`
(melania resync/verify ✅). Висновок — у `docs/learnings.md`. PR #16 (merge за згодою власника).
**Ітерації 2–3** (PR #16, #17 змерджено): закрито прогалину G5 (пам'ять між сесіями) — **повний
авто-цикл** `automations/g5-consolidate` (Stop) + `automations/g5-retrieve` (SessionStart) → **G5 ✅**;
`gmi-audit` розширено G5/G7-пробами. Відкриті лише P2-нитки (`experiments/gmi-g5-memory/g5-package.md`).

## Фаза 6 — Перший реальний проєкт: мобільний агент 🟡 (зріз ✅, продукт — попереду)
Вихід із режиму «полірування інструментів» у режим «створення продукту» (P0 ретроспективи
2026-07-24). `projects/mobile-agent/` — **Кишеньковий агент**: AI-агент, що працює прямо зі
смартфона, без ПК і без сервера. Один самодостатній HTML (~55 КБ) ставиться на головний екран.
- **Зріз (vertical slice) ✅:** ввід (текст/голос) → відповідь → нотатка на пристрої → пошук;
  три двигуни з деградацією **хмара → локальна (WebLLM) → офлайн**, де найнижчий рівень
  корисний без мережі, ключа й WebGPU; ключ API — AES-GCM + пароль-фраза; PWA з авто-оновленням.
- **Перевірено ділом:** 85 тестів логіки/збірки/PWA-інваріантів + 29 перевірок у реальному
  Chromium (емуляція Pixel 7), включно з повністю офлайн-сценарієм. Набір лабораторії — 119.
- **Далі (не в зрізі):** фізичний телефон + локальна модель на WebGPU; APK через GitHub Actions
  (лише якщо PWA доведе щоденну цінність); IndexedDB і ланцюжок діалогу за потреби.
