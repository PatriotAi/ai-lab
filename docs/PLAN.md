# Деталізований план лабораторії · ai-lab / ШІ-лаб

> **Статус:** планування. Виконання — поетапно, коли середовище дозволить повну роботу.
> **Канонічна мова — українська**; англійські версії дзеркалять її і не дають розходитися.

Цей документ — єдине джерело правди для розгортання лабораторії. Він зводить разом:
узгоджене з Copilot-сесії, вимогу білінгвальності (UA-first) і вже залитий фундамент.

## 0. Узгоджені параметри (single source of truth)
- **Назва:** GitHub `ai-lab` / укр. «ШІ-лаб»
- **Власник:** персональний акаунт PatriotAi
- **Мета:** центральне сховище для опрацювання та прототипування багатомовних проєктів з AI
- **Призначення:** зразки/шаблони → допрацювання → виніс в окремі репозиторії
- **Мови програмування:** індивідуально під проєкт (не фіксовані)
- **AI-помічники:** Claude / Claude Code, Codex, інші AI-сервіси
- **Документація:** білінгвальна, **UA-first** зі швидким перемиканням UA⇄EN
- **Безпека:** повний набір (секрети, вразливості, SAST, залежності, рев'ю)
- **Ліцензія:** ⚠️ зараз Apache-2.0; Copilot пропонував MIT — потрібне рішення (§Рішення)

### Дві теки для роботи (не плутати)
- `experiments/` — **маленькі гіпотези**, які швидко перевіряємо й лишаємо/прибираємо.
- `projects/` — **повноцінніші зразки**, які допрацьовуємо й виносимо в окремі репозиторії.

## Фаза 1 — Білінгвальний шар (UA-first) 🕒
Мета: українська **завжди присутня**, з повним перекладом і перемиканням.
1. `README.md` → білінгвальний лендинг з мовною навігацією (🇺🇦 Українською | 🇬🇧 English),
   UA-секція перша.
2. `docs/ua/` + `docs/en/` — паралельні дерева; **UA — канон**, EN — дзеркало:
   `setup.md` (налаштування), `guidelines.md` (правила/конвенції), `ai-integration.md`
   (Claude / Codex / MCP). Кожен файл лінкує на свою пару (EN ▸ / UA ▸).
3. Перенести наявні `docs/*.md` (methodology, roadmap, learnings, glossary) у `docs/ua/`
   і створити EN-дзеркала. (Залежить від рішення §2.)
4. `CODE_OF_CONDUCT.md` — кодекс поведінки (UA/EN).
5. Білінгвальні коментарі в конфігах (workflows, pre-commit, `.env.example`, trivy).
6. **Конвенція:** UA — джерело правди; EN оновлюємо в тому ж PR (не розходяться).

## Фаза 2 — Довершення безпеки та CI 🕒/⛔
1. `.github/workflows/code-quality.yml` — розширити поточний `lint.yml`: pre-commit +
   actionlint + форматування за мовами (коли з'явиться код).
2. `.github/workflows/dependencies.yml` — `dependency-review-action` (рев'ю залежностей у PR).
   *Виправлення чернетки Copilot:* `dependabot.yml` лишається в `.github/`, **не** в `security/`.
3. `scripts/setup.sh` — бутстрап: встановити `pre-commit`, hooks, перевірити оточення.
4. `scripts/security-check.sh` — локально прогнати gitleaks + Trivy + pre-commit одним викликом.
5. `projects/project-template/` — додати `.gitignore` і `src/.gitkeep`.
6. ⛔ **Branch protection** для `main`: обов'язкові PR + рев'ю + зелені перевірки
   (`security`, `code-quality`). Потрібен доступ до GitHub API/налаштувань.
7. ⛔ Увімкнути **code scanning / secret scanning** (Settings → Security).

## Фаза 3 — Двигун продуктивності (навички та автоматизації) 🕒
Серце лабораторії — «створювати / покращувати / винаходити».
1. `skill-new` — фабрика навичок (шаблон → нова навичка за хвилини). *Компаундний пріоритет.*
2. `SessionStart`-хук — щосесії підвантажує контекст (конвенції, статус, глосарій).
3. `translate-uaen` — двомовна локалізація з глосарієм (рушій білінгвальності).
4. Контент-пайплайн: `deep-research` → чернетка → переклад UA/EN → рев'ю.
5. `publish` — текст → Canva-картка (Canva MCP) → деплой прев'ю на Vercel (Vercel MCP).
6. `weekly-review` — щотижнева ретроспектива (через `/loop` або `send_later`).

## Рішення, потрібні від тебе
1. **Ліцензія:** лишаємо **Apache-2.0** (рекоменд. — патентний захист) чи переходимо на **MIT** (як радив Copilot)?
2. **Модель білінгвальності docs:** (А) паралельні `docs/ua` + `docs/en` (як у плані Copilot)
   чи (Б) один файл із UA+EN секціями. **Рекоменд.: (А)** — чистіше перемикання.
3. **`README_UA.md` окремо?** Рекоменд.: ні — `README.md` уже білінгвальний із повною
   UA-секцією (менше дублю). Якщо хочеш строго за планом Copilot — додам окремий `README_UA.md`.
4. **Перший експеримент Фази 4:** `skill-new` / контент-пайплайн / `publish` / інше.
