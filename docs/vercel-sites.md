## Спільна базова лінія (мінімум для кожного сайту)

1. `package.json`: `"engines": {"node": "24.x"}` — Vercel припинив підтримку Node 20.x,
   збірка падає з `BUILD_UTILS_NODE_VERSION_DISCONTINUED` (див. learnings 2026-10-01).
2. `npm audit` без рівня high і `npm outdated` порожній; перевіряти щомісяця.
3. `npm run build` проходить; `vite preview` + `curl` усіх маршрутів дають 200.
4. SPA з `BrowserRouter` має `vercel.json` з rewrite на `/`.
5. Є `.gitignore`, `package-lock.json`, `.env.example`; секрети — лише через env.

## Протокол сесії над сайтом

**Старт.**
1. При створенні сесії додай `patriotai/ai-lab` **додатковим джерелом** — тоді `CLAUDE.md`
   і SessionStart-хук підхоплюються автоматично, а цей файл доступний без вставляння.
2. Прочитай свій рядок реєстру, базову лінію й чергу. Стан PR і гілок бери повним
   списком через API, не лише з `git branch`.

**Робота.**
3. Нова гілка від свіжого `main`; чужих гілок не чіпай; нічого не видаляй і не
   переписуй — лише додавай (merge-not-replace).
4. Незворотне — merge, налаштування Vercel, секрети — лише за свіжою явною згодою власника.

**Завершення.**
5. Онови свій рядок реєстру й чергу малим docs-PR у ai-lab.
6. Нова знахідка → запис у `docs/learnings.md`.

**Межа каналу.** Прямі повідомлення між сесіями доходять лише до **запущених** сесій;
станом на 2026-10-01 жодної запущеної, окрім поточної, не було [C]. Тому на пряме
повідомлення не покладаємося: стан живе в цьому файлі, `learnings.md` і PR. Стан
зупинених сесій видно через список сесій (статус, остання дія).

## Стартовий промпт для сесії сайту

Замість довгих інструкцій достатньо вставити:

```
Підключи patriotai/ai-lab додатковим джерелом. Прочитай docs/vercel-sites.md:
мій рядок реєстру, базову лінію й чергу. Виконай пункти черги для цього
проєкту за протоколом. Нічого не видаляй і не переписуй; merge не виконуй.
Наприкінці онови рядок реєстру та docs/learnings.md.
```
