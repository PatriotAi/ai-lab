## Як запустити НОВУ серію-дослідження
1. Відкрий **нову сесію** Claude Code на `patriotai/ai-lab` (та сама головна версія — увесь контекст і навички підвантажаться самі).
2. Назви тему + скажи **«новий експеримент»** → скіл `experiment` створить `experiments/<тема>/` за циклом гіпотеза→дизайн→запуск→вимір→висновок.
3. Працюй у чистому процесі: гілка від `main` → пакунок (PR) → перевірки → **merge за згодою власника**.
4. Висновок запиши в `docs/learnings.md` (компаундна пам'ять), онови цей `CONTEXT.md` за потреби.
