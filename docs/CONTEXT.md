## Перший реальний проєкт (Фаза 6) — нове
- **`projects/mobile-agent/` — «Кишеньковий агент»**: AI-агент прямо зі смартфона, без ПК і без
  сервера. Один самодостатній HTML (~55 КБ) ставиться на головний екран; три двигуни з деградацією
  **хмара → локальна (WebLLM) → офлайн**, де найнижчий рівень корисний без мережі, ключа й WebGPU.
- Ключ API — лише на пристрої й лише зашифрованим (AES-GCM + пароль-фраза). Секретів у репо нема.
- Перевірено ділом: **119 перевірок** у наборі лабораторії (з них 85 — проєкту) + **29** у реальному
  Chromium (емуляція Pixel 7, включно з офлайн-сценарієм): `node tests/mobile-agent-browser.mjs`.
- Знахідка, що змінює патерн: **реєстрація service worker з `blob:`-URL заборонена браузером** —
  «повністю один файл» і справжній офлайн несумісні, потрібен окремий `sw.js`. Патч навички
  `pwa-to-android-app` (Pattern 1) — окремо, через MA-протокол.
