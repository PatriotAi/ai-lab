## Перший реальний проєкт (Фаза 6) — нове
- **`projects/mobile-agent/` — «Кишеньковий агент»**: AI-агент прямо зі смартфона, без ПК і без
  сервера. Один самодостатній HTML (~55 КБ) ставиться на головний екран; три двигуни з деградацією
  **хмара → локальна (WebLLM) → офлайн**, де найнижчий рівень корисний без мережі, ключа й WebGPU.
- Ключ API — лише на пристрої й лише зашифрованим (AES-GCM + пароль-фраза). Секретів у репо нема.
- Перевірено ділом: **85 перевірок** проєкту в наборі лабораторії (усього в наборі — 150) + **29** у реальному
  Chromium (емуляція Pixel 7, включно з офлайн-сценарієм): `node tests/mobile-agent-browser.mjs`.
- Знахідка, що змінює патерн: **реєстрація service worker з `blob:`-URL заборонена браузером** —
  «повністю один файл» і справжній офлайн несумісні, потрібен окремий `sw.js`. Патч навички
  `pwa-to-android-app` (Pattern 1) — окремо, через MA-протокол.

## Доказовість тверджень (Core Rule 14) — нове
- **Правило:** фактичне твердження несе тег **[E]** перевірено ділом (з вказівником на прогін/тест/дату) ·
  **[C]** обґрунтоване, машинно не перевірене · **[S]** гіпотеза. Директиви НЕ тегуються.
  Нема доказу → **звузь формулювання**, не лишай широку обіцянку.
- **Механіка:** `maintain.py verify` блокує (1) скіл без секції `Critical Facts`, (2) факт без тега,
  (3) `[E]` без вказівника і (4) `[E]` зі вказівником, **якого немає на диску** — формат вказівника
  не є доказом. Секція обов'язкова в **усіх 28** скілах: доти гейт покривав 2 з 28, решта проходила
  порожньо. Методика — `validation-mesh` (Claim-Evidence Layer); enforcement перед видачею —
  `pre-delivery-gate`; у CI — крок «Гейт екосистеми melania».
- **Чому:** 5 випадків класу «обіцянка ширша за перевірене» (2026-07-19…26), **жоден не спіймала
  самоперевірка** — автор твердження пише й тест. Для критичних [E] шукати перевіряча поза собою.
- Чесний факт після зачистки: з 10 фактів у скілах лише **один** має [E] — решта [C].

## Самоперевірний протокол (Core Rule 15) — нове
- **Правило:** крок, який звітується словами («bump зроблено», «H1 синхронізовано»), мусить мати
  машинну перевірку — інакше він тихо порушується, а звіт цього не показує. **Звіт ≠ доказ.**
- **Покриття перевірки** визначає ПЕРЕЛІК ІНЦИДЕНТІВ, які вона закриває, а не число: «canary ×3»
  дало три чесні канарки при чотирьох дірках. Кожну перевірку прогнати на **зламаному** стані.
- **Механіка:** `maintain.py verify` — версійна тріада (frontmatter/H1/банер/MANIFEST/CHANGELOG) ·
  крос-посилання `П.N` за ідентифікатором · лічильники про інший файл · текстова гігієна
  (омоглифи, чужомовні літери). Історія (`## Зміни`) не перевіряється — там цитати минулого.
- **Підстава:** чотири дрейфи пережили попередню хвилю ПОПРИ чесні звіти про виконання.
