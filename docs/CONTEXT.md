## Governance (коротко)
- Пріоритет: **явний запит власника → правила лабораторії (`CLAUDE.md`) → протокол melania → SKILL.md**.
- **merge будь-якого PR у `main` — лише за явною згодою власника.** Пре-схвалення melania діє
  максимум до *відкриття PR*.
- melania-екосистема: перед комітом змін — `maintain.py verify` (exit 0); після свідомого
  оновлення — `resync` → `verify`. Downgrade/видалення навички — стоп і спитати власника.
- Жодних секретів у репо (лише env); перед комітом — `pre-commit` (`scripts/setup.sh`).
