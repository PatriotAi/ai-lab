# Конвенції лабораторії

> Мова: **Українською** · [English](../en/guidelines.md)

## Мова
- **Українська — джерело правди.** EN — дзеркало, оновлюється в тому ж PR.
- Робочі журнали (`roadmap`, `learnings`, `PLAN`) — UA-канон без обов'язкового EN-дзеркала.
- Онбординг-доки (`setup`, `guidelines`, `ai-integration`) — двомовні пари `ua/` + `en/`.

## Цикл роботи
Гіпотеза → дизайн → запуск → вимір → **лиши/прибери** → висновок у `../learnings.md`.
Спершу наскрізний зріз (vertical slice), потім розширення. Деталі — [`../methodology.md`](../methodology.md).

## Куди що класти
- Гіпотеза → `experiments/`; проєкт-зразок → `projects/`.
- Навичка → `.claude/skills/<name>/SKILL.md`; хук/пайплайн → `automations/`; утиліта → `scripts/`.

## Правила
- **Одна автоматизація — одна відповідальність.** Без дублів і шуму.
- **Жодних секретів** — лише env (див. [`../../SECURITY.md`](../../SECURITY.md)).
- Кожна навичка/автоматизація = тека з коротким README/SKILL.md і чітким тригером.
- Перед великими/незворотними змінами — план (plan mode).
