# Робота з AI-помічниками

> Мова: **Українською** · [English](../en/ai-integration.md)

Лабораторія розрахована на роботу з AI: Claude / Claude Code, Codex та інші сервіси.

## Контекст для асистента
- Головний контекст — [`../../CLAUDE.md`](../../CLAUDE.md): мова, структура, конвенції.
- Методологія — [`../methodology.md`](../methodology.md); план — [`../PLAN.md`](../PLAN.md).

## Можливості Claude Code
- **Навички (skills)** — `.claude/skills/<name>/SKILL.md`; нову створюй через `/skill-new`.
- **Хуки** — події сесії (`SessionStart`, `Stop`) через `settings.json`.
- **Субагенти**, **slash-команди**, **plan mode**, фонові задачі.

## MCP-інтеграції
- **GitHub** — код, PR, issues.
- **Vercel** — деплой/прев'ю.
- **Canva** — дизайн-ассети.

## Безпека з AI
- Жодних секретів у промптах, навичках, комітах — лише env.
- Мінімальні скоупи токенів. Перед незворотними діями — план і підтвердження.
