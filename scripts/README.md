# scripts/ — допоміжні утиліти

Невеликі скрипти для рутинних задач лабораторії (bash/python тощо).

## Правила
- Один скрипт — одна задача; зверху короткий коментар «що робить / як запускати».
- Жодних секретів усередині — лише через env (див. `../SECURITY.md`).
- Виконувані скрипти познач `chmod +x`.
