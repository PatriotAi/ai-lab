- **Стек ефективності P1–P7** (чому мозок ощадний): P1 пам'ять+обчислення разом · P2 розріджені спайки ·
  P3 аналог/низька точність · P4 паралельність · P5 «лише несподіванка» (predictive) · P6 критичність ·
  P7 фізика-native. (P8 квант — [S], не спираємо.)

  (консолідація на Stop `g5-consolidate` + витяг на SessionStart `g5-retrieve`) працює.
- **Теги/скорочення:** [E] встановлене · [C] дискусійне · [S] спекулятивне-гіпотеза ·
  RQM = Relational Quantum Mechanics (спостерігач = будь-яка система, не конче свідомість) ·

  2 = `gmi-g5-memory` (пам'ять + cold-start recovery); 3 = `gmi-g5-auto` (авто-цикл: консолідація+витяг).
- **Де первинники:** визначення+джерела → `experiments/gmi/{invariants.md, sources.md, g7-commit-protocol.md}`;
