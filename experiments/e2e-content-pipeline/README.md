## Дизайн (найменший крок)
Тема: **«SessionStart-хуки Claude Code: робочий контекст щосесії»** — вузька,
з власним кейсом (`automations/session-start/`). Ланцюжок:
`/content-pipeline` (дослідження: 2 офіційні джерела + власний кейс → UA-чернетка)
→ `/translate-uaen` (EN-дзеркало) → рев'ю за глосарієм → `/publish`
(Canva MCP → картка; Vercel MCP → прев'ю).

## Кроки
1. Дослідження: офіційна документація hooks (2 джерела) + кейс лабораторії.
2. UA-чернетка `artifact.md` (канон, джерела лінками).
3. EN-дзеркало у тому ж файлі (`translate-uaen`, глосарій).
4. Рев'ю: терміни/факти/розмітка.
5. Publish: Canva-картка + Vercel-прев'ю; лінки — сюди і в артефакт.
6. Вимір → Результат; висновок → `docs/learnings.md`.
