# G7 commit-протокол — детермінація / read-out (закриття прогалини System Core)

- **Дата:** 2026-07-14 · **Серія:** GMI · нитка T4 · **Статус:** протокол-шаблон готовий
- **Контекст:** G7 (інваріант «детермінація/read-out») у System Core був 🟡 — присутній неявно
  («вибір домінантного вектора»), але не формалізований. Цей протокол закриває прогалину.

## Що таке G7 (нагадування)
Момент, коли система перетворює **невизначений розподіл кандидатів** на **зафіксований
результат** — і робить це відстежувано. Це наш «спостерігач» (патерн *невизначене → визначене*).
Ключове (D3): «спостерігач» **не мусить бути свідомим** (RQM) — це будь-яка операція read-out.

## Протокол (5 кроків)
```
[G7-COMMIT]
1. CANDIDATES  — перелік кандидатів-гіпотез {c1..cn} з вагами/оцінками (звідки взяті).
2. CRITERION   — явний критерій відсіву: поріг · бритва Оккама · більшість/голос ·
                 атрактор (найстійкіший стан) · очікувана корисність. Назви, ЯКИЙ і ЧОМУ.
3. COMMIT      — обраний результат R = argmax/threshold за критерієм.
4. RESIDUAL    — залишкова невизначеність: суперники, що майже пройшли; впевненість (0–1);
                 за яких нових даних рішення переглядається (тригер re-open).
5. TRACE       — один рядок у журнал: {R · критерій · впевненість · дата}.
```

## Приклад (на нашому ж дослідженні)
`CANDIDATES`: квант-субстрат [S] · динаміка потоку [E] · стек-ефективність [E].
`CRITERION`: доказовість (перевага [E] над [S]) + бритва Оккама.
`COMMIT`: «інтелект-як-потік» на [E]-основі; квант **не** спираємо.
`RESIDUAL`: квант лишається [S]-ниткою (re-open, якщо з'явиться фальсифіковане передбачення); впевненість ~0.85.
`TRACE`: `2026-07-13 · R=потік[E] · критерій=доказовість+Оккам · conf=0.85`.

## Мапа на System Core «Гіперрозум»
| Крок Core (як було) | Крок G7 (формалізовано) |
|---|---|
| «варіанти для H2 (2a/2b/2c)» | 1. CANDIDATES |
| «бритва Оккама», «стрес-тест» | 2. CRITERION |
| «вибір домінантного вектора» | 3. COMMIT |
| *(бракувало)* | 4. RESIDUAL — **новий, ключовий: не втрачати «наскільки впевнені»** |
| «[АРХІВНА ВИТЯЖКА]» | 5. TRACE |

**Результат:** System Core G7 🟡→✅ — додано явний крок **RESIDUAL** (фіксувати невизначеність)
і **TRACE** (журнал рішення). Проба вже є в `gmi-audit`; тут — повний шаблон.

## Інтеграція
- `gmi-audit`: G7-проба тепер спирається на цей шаблон (5 кроків як критерій оцінки 🔴/🟡/✅).
- Застосовність: будь-яка когнітивна система / агент — вставити `[G7-COMMIT]` у точку рішення.
