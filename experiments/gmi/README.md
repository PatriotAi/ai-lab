## 0. Контекст і чому саме зараз

Завантажені матеріали — діючий екземпляр «загальної системи мислення»: мета-промпт
**«Гіперрозум / System Core v1.2»** (first-principles, епістем-стек, фазове дерево,
протокол пам'яті «стиснення+індексація») + дві демонстрації. Обидві демо не випадкові:
**походження часу як самоорганізація інформації** та **вихрова/круговоротна система** —
вони вказують на одну **процес-онтологію**, яку власник тепер формалізує: реальність та
інтелект як **динаміка потоку інформації**, а не набір деталей.

GMI для нас — **не абстрактне «що таке інтелект»**, а зв'язка трьох питань: *(1)* які
динамічні інваріанти спільні для всіх серйозних рамок; *(2)* **який принцип дає мозку
його ефективність** (розум завбільшки з мозок, на ~20 Вт, що переважає суперкомп'ютери);
*(3)* що з цього **уможливлюване** на нинішніх/близько-майбутніх компонентах.

## 0-bis. Епістемічний контракт (рятує від псевдонауки)

Тема межує зі спекулятивним. Тому — **радикальна строгість** (узгоджено з самим System Core:
«етос інтелектуальної чесності»). У всіх нотатках кожне твердження тегуємо:

- **[E] Established** — усталена наука з рецензованими джерелами (термодинаміка обчислень,
  нейроморфіка, predictive processing, нейронні хвилі/критичність, енергетика мозку).
- **[C] Contested** — активна дискусія, часткові докази (квантові теорії пізнання, критичність
  як «двигун» інтелекту).
- **[S] Speculative** — гіпотеза-лінза власника без прямих доказів («круговорот/вихор як основа
  інтелекту», «квантова заплутаність як субстрат розуму»). Беремо як *ліхтар для пошуку*,
  тримаємо фальсифікованою, **не видаємо за факт**.

Квантову й вихрову рамку я **не відкидаю і не проголошую істиною** — досліджую чесно й
позначаю рівнем доказовості.

## 1. Гіпотеза (v2) — три залежні частини

**H-A (означувальна: інваріанти-як-динаміка).**
Крізь сімейства рамок (*AGI-визначення · теорії інтелекту · world-models · cognitive
architectures*) проходить **мала множина (≈5–7) динамічних інваріантів** — не модулів, а
**режимів потоку інформації** (передбачення, рекурентність, маршрутизація уваги, атракторна
пам'ять…). GMI означуване як цей набір *течій*, а не деталей.

**H-B (субстратно-енергетична — головна за вагою).**
Брейн-рівневий загальний інтелект при **~20 Вт / ~1.3 л**, що переважає нинішні суперкомп'ютери,
можливий через **ідентифіковні фізично-обчислювальні принципи ефективності** (а не лише «еволюція
довго тюнила»); і ці принципи **частково переносні** на інженерні субстрати, доступні сьогодні /
у близькому майбутньому.

**H-C (grounding + здійсненність).**
Набір інваріантів і принципів ефективності відображаємо на *(i)* власний **System Core**
(що реалізує / чого бракує) і *(ii)* **конверт здійсненності** — що нинішні/близько-майбутні
компоненти (нейроморфіка, аналогові in-memory, фотоніка, мемристори, розріджені моделі, 3D-інтеграція)
реально уможливлюють у напрямку цілі-північ.

### Ціль-північ (target spec для «уможливлюваного» GMI)
| Вимір | Орієнтир |
|---|---|
| **Здатність** | ≥ найрозумніша людина (загальна, не вузька) |
| **Об'єм** | ≤ людський мозок (~1.2–1.4 л) |
| **Енергія** | ≤ людина (~20 Вт) **або** добування енергії тим самим принципом без надлишку ресурсів |
| **Свобода змінних** | дозволені альтернативні/експериментальні/**над-людські** рішення — здібності, яких еволюція людині не дала, але які **еволюційно доступні** штучному над-інтелекту |

### Кандидат-набір інваріантів, переосмислений як динаміка (перевіряємо на кроці 2)
| # | Інваріант (як течія) | Динаміка/потік | Слід у рамках | Слід у System Core |
|---|---|---|---|---|
| I1 | **Модель світу** | генеративний потік передбачення середовища | world-models; FEP; predictive coding | епістем-стек, «карта знань» |
| I2 | **Ціль / вектор цінності** | градієнт, що спрямовує потік | RL-reward; active inference | «мета-гіпотеза», вибір вектора |
| I3 | **Абстрагування** | стиснення потоку в інваріанти (масштаби) | g-фактор; ієрархія; ренормалізація | «багаторівнева абстракція» |
| I4 | **Висновок/планування** | пошук-хвиля над моделлю | SOAR; планувальники; sampling | фазове дерево, розгалуження гілок |
| I5 | **Пам'ять/інтеграція** | атракторна динаміка, стиснення+індекс | ACT-R; Хопфілд; зовн. пам'ять | протокол «стиснення+індексація» |
| I6 | **Навчання/адаптація** | мінімізація похибки-потоку | FEP; RL; пластичність | фальсифікація, peer-review-цикл |
| I7 | **Метакогніція** | рефлексивна петля моніторингу | Global Workspace; self-model | «постійний самоаналіз контексту» |
| I8 | **Генералізація/перенос** | інваріантність течії між доменами | ядро «general»; трансфер | той самий Core → час *і* гідродинаміка |

> 8 — навмисно широка стартова сітка. На кроці 2 звужуємо до **5–7**, зливаючи/відкидаючи
> **спираючись на джерела** (не «на око»), кожен лишений — крос-валідований у ≥2 рамках.

## 2. Критерії успіху (v2)

1. **Покриття** (deep-research). ≥4 сімейства рамок **плюс** субстратно-енергетичний блок;
   у кожному кластері **≥3 фактчекнуті джерела, первинні за можливості**.
2. **Крос-валідація інваріантів.** Кожен інваріант фіналу — у **≥2 незалежних рамках**
   (`validation-mesh`), інакше це артефакт однієї школи.
3. **Мапа ефективності (gap-map).** Реальні числа + джерела: **мозок vs суперкомп'ютер vs
   нейроморфіка/edge** за здатністю / об'ємом / енергією; названо принцип(и) переваги мозку.
4. **Строгість [E]/[C]/[S].** Кожне ключове твердження тегнуте рівнем доказовості; жодного
   спекулятивного — як факту.
5. **Чесна фальсифікація.** ≥1 реальна спроба зламати набір/принцип (напр. embodied-інтелект
   без явної «моделі світу»; або «немає єдиного принципу ефективності — лише агрегат»).
6. **Конверт здійсненності + grounding.** System Core → інваріанти (прогалини) **і** чесний
   перелік: що близько-майбутні компоненти уможливлюють, що ні, які невідомі.
7. **Двомовний артефакт** UA-канон + EN (`translate-uaen`), через `pre-delivery-gate`.

**Поріг «успіх»:** критерії 1–7; набір інваріантів і принаймні один принцип ефективності
**пережили** фальсифікацію уточненням, а не колапсом; конверт здійсненності — з чесними невідомими.

## 3. Не-мета (out of scope)

- ❌ **Не будуємо** над-інтелект і не «вирішуємо» свідомість/природу часу. Ціль — **вагомі
  гіпотези + результати + конверт здійсненності**, не готова система.
- ❌ Не видаємо [S]-лінзи (квант/вихор) за доведене; не робимо псевдонауку.
- ❌ Не рахуємо CFD вихрового рушія — вихор цікавий лише як *метафора динаміки/переносу* (I8).
- ❌ Не вичерпний огляд усієї нейронауки — репрезентативний зріз, достатній для інваріантів і gap-map.

```

   ▼

   │ content-pipeline + translate-uaen → pre-delivery-gate
   ▼ experiments/gmi/artifact/  (публікація: рішення на кроці 4)
висновок → docs/learnings.md; docs/CONTEXT.md; glossary (крок 5)
```

**Кластери збору (крок 2):**
- **C1 — GMI-рамки:** AGI-визначення; теорії інтелекту (g, множинний, триархічний);
  world-models; cognitive architectures (SOAR, ACT-R, Global Workspace).
- **C2 — Фізика/енергетика обчислень:** межа Ландауера, термодинаміка обчислень,
  оборотні обчислення; **енергетика мозку** (~20 Вт, ~10¹⁵–10¹⁶ оп/с) vs суперкомп'ютери.
- **C3 — Субстрати:** нейроморфіка (Loihi, SpiNNaker, TrueNorth), аналогові in-memory /
  мемристори, фотоніка, розріджені/подієві обчислення, 3D-інтеграція.
- **C4 — Динаміка інтелекту (течії/хвилі):** predictive processing / Free Energy Principle /
  active inference; нейронні осциляції та **біжучі хвилі**; критичність / self-organized criticality;
  динамічні системи в когнітивістиці.
- **C5 — Квантова/заплутаностна лінза [C]/[S]:** Orch-OR (Penrose–Hameroff) і його статус;
  квантові обчислення для ШІ; інформаційно-теоретичні межі. Чесний розбір.
- **C6 — Здійсненність + grounding:** сучасний AI-compute (енергія навчання/інференсу LLM) vs мозок;
  дорожні карти близького майбутнього; мапа на System Core.

**Артефакти теки:**
