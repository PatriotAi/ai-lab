|---|---|---|
| G1 Модель світу | 🟡 частково | епістем-стек + «карта знань» — **явна/лінгвістична, не вивчена передбачувальна** |

| G6 Метакогніція | ✅ сильний | «постійний самоаналіз контексту», проактивні витяжки |
| G7 Детермінація/read-out | 🟡 частково | «вибір домінантного вектора» є, але **не формалізований** як commit-протокол |

- **Генеральність:** ✅ є (той самий Core → походження часу *і* гідродинаміка = крос-домен перенос).
- **Ефективність (осі P):** N/A як субстрат — Core працює на дата-центровій LLM (протилежність цілі-північ);
  це **методологічний харнес міркування**, не субстрат. Оцінюємо лише інваріанти, не Вт/літри.
- **Read-out:** присутній як людино-в-циклі/модель-вибір; бракує явного «розподіл→поріг→результат+невизначеність».

## Прогалини → дія (пріоритет)
1. **🔴 G5** — навчання між сесіями (авто-консолідація понад ручний `[АРХІВНА ВИТЯЖКА]`). **← кандидат наступної ітерації.**
2. 🟡 G1 — шар предикції/retrieval, що *передбачає*, а не лише каталогізує.
3. 🟡 G7 — явний commit-протокол.
