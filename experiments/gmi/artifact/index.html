GMI · General Model of Intelligence · 2026-07-13

Не «ще одна теорія розуму», а спільний кістяк усіх серйозних рамок: сім динамічних інваріантів, стек принципів ефективності мозку — і чесна вісь спостерігача, де обчислення стає результатом. Кожне твердження позначене рівнем доказовості. Not “another theory of mind”, but the shared skeleton across the serious frameworks: seven dynamic invariants, a stack of brain-efficiency principles — and an honest observer axis where computation becomes a result. Every claim is tagged by evidence level.

The owner’s thesis — “computation yields a result only upon an act of observation” — turns out to be the same indeterminate → (read-out) → determinate pattern at three levels. That is invariant G7.

«Спостерігач ≠ конче свідомість; може бути інша змінна». VALID — дослівно збігається з Ровеллі: спостерігач = будь-яка фізична система (електрон, лічильник).“The observer need not be conscious; it can be another variable.” VALID — matches Rovelli exactly: an observer is any physical system (an electron, a detector).

«Потрібен саме свідомий спостерігач, інакше не існує». UNKNOWN — фон Нейман–Вігнер відсунуто (Вігнер відмовився після декогеренції), але чесна щілина «чому вихід унікальний» лишається відкритою.“A conscious observer is required, else it doesn’t exist.” UNKNOWN — von Neumann–Wigner was sidelined (Wigner recanted after decoherence), yet the honest “unique-outcome” gap stays open.
✓ [E/C]
«Чи може мозок бути глибоким спостерігачем сам собі?» Так — FEP-марковська ковдра (self-evidencing) + Global Workspace: мозок «спостерігає» власні стани.“Can the brain be its own deep observer?” Yes — the FEP Markov blanket (self-evidencing) + Global Workspace: the brain “observes” its own states.
— [S]
«j-space» (підсвідомий фактор) — термін власника; мапиться на латентний / передсвідомий простір — розподіл ДО коміту G7. Робоча назва, не доведена сутність. Буквальний квант-субстрат — INVALID (декогеренція за фемтосекунди), тримаємо як [S]-нитку.“j-space” (a subconscious factor) — the owner’s term; maps onto a latent / preconscious space — the distribution BEFORE the G7 commit. A working name, not a proven entity. A literal quantum substrate is INVALID (femtosecond decoherence); kept as an [S] thread.

Інженерний виграш: G7 у переносному вигляді = атракторний коміт / поріг accumulation — субстрат-нейтральний і будується. Квантова версія — той самий патерн, але не обов'язкова. Engineering payoff: G7 in transferable form = an attractor commit / accumulation threshold — substrate-neutral and buildable. The quantum version is the same pattern, but not required.

Чому мозок такий ощадний — це СТЕК, не один принципWhy the brain is so efficient — it’s a STACK, not one principle

П'ять гіпотез для побудовиFive hypotheses to build on

  1. [E/C] Ефективність = архітектурний стек, не магія. Брейн-паритет по енергії досяжний для вузьких задач уже сьогодні; вузьке місце — генеральність при тій же ефективності.[E/C] Efficiency = an architectural stack, not magic. Energy brain-parity is reachable for narrow tasks today; the bottleneck is generality at that same efficiency.
  2. [E] «Потік/хвиля/круговорот» — легітимна онтологія (FEP + біжучі хвилі + критичність), реалізовна без квантів. Вихор — лише візуальна модель, не сама структура.[E] “Flow / wave / circulation” is a legitimate ontology (FEP + traveling waves + criticality), realizable without quantum. The vortex is only a visual model, not the structure itself.
  3. [E] G7 (детермінація/read-out) — інженерно-ключовий і будується як атракторний коміт; «спостерігач» не мусить бути свідомим (RQM).[E] G7 (determination/read-out) is engineering-critical and builds as an attractor commit; the “observer” need not be conscious (RQM).
  4. [C/S] Сильна теза «свідомість творить результат» — відкрите питання (щілина унікальних виходів); тримаємо як дослідницьку ставку, не як фундамент.[C/S] The strong “consciousness makes the result” thesis — an open question (the unique-outcome gap); kept as a research bet, not a foundation.
  5. Дорожня гіпотеза: над-людський, але брейн-паритетний інтелект ≈ стек ефективності (P1–P7) × повний набір інваріантів (G1–G7) з домен-інваріантністю; над-людські «еволюційно недосяжні» змінні додаються ПОНАД цей мінімум.Roadmap hypothesis: a superhuman yet brain-parity intelligence ≈ the efficiency stack (P1–P7) × the full invariant set (G1–G7) with domain-invariance; superhuman “evolution-inaccessible” variables are added ON TOP of that minimum.
