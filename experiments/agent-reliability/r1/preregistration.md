# R1 — чи навичка взагалі допомагає: пре-реєстрація

- **Записано:** 2026-11-07, до першого прогону.
- **Джерело:** офіційний `claude plugin eval` (документація Claude Code «Test plugins with evals»,
  звірено 2026-11-06; CLI у сесії — 2.1.318, вимога ≥ 2.1.269): кожен кейс ганяється з плагіном і
  без нього, різниця балів — Δ; оцінювач `tool_used: Skill` показує, чи навичку взагалі обрано.

## Що міряємо
Дві навички з різним характером:
- **`semantic-router`** (Melania) — задає власний формат відповіді «Routing Decision»; самодостатня.
- **`translate-uaen`** (лабораторна) — тримається на файлі репозиторію `docs/glossary.md`; у
  порожньому робочому каталозі прогону цього файла нема.

Тимчасовий плагін збирає `build_plugin.py` у теці сесії (копії двох навичок + кейси), робочий
маркетплейс не змінюється.

## Кейси (4) і оцінювачі (лише детерміновані, без судді-моделі)
| Кейс | Запит природними словами | Оцінювачі |
|---|---|---|
| router-a | Які навички використати, щоб перекласти README двома мовами й опублікувати картку? | `tool_used: Skill` (semantic-router); `regex` «Routing Decision» |
| router-b | Не знаю, з чого почати: треба одночасно дослідити тему й зробити з неї двомовний пост. | ті самі |
| translate-a | Переклади англійською: «Гейт зупиняє незворотні дії без записаної згоди власника.» | `tool_used: Skill` (translate-uaen); `regex` наявність англійського речення з `gate` |
| translate-b | Зроби двомовним (UA/EN) речення «Реєстр розбитих вікон — живий перелік відомого боргу.» | `tool_used: Skill` (translate-uaen); `regex` «UA» і «EN» у відповіді |

3 прогони на кейс і плече (типово), найдешевший клас моделі, стеля вартості — `--max-cost-usd 5`.

## Пороги (рішення до прогону)
- **Тригер:** навичку обрано природним формулюванням у ≥ 2 з 3 прогонів кейсу. Інакше — `description`
  навички слід переписати (окремим кроком, після рішення власника).
- **Приріст:** Δ > 0 для кейсів router-a/b (формат дає лише навичка) — очікування [S].
- **translate-uaen поза репо** — очікування [S]: Δ ≈ 0, бо навичка тримається на `docs/glossary.md`;
  якщо так — це межа переносності навички, записуємо.
