## Рішення дизайну і незворотність
- **Окрема тека, Фаза 13 не змінюється.** незворотність: `reversible` — тека видаляється без наслідків.
- **Прототипи хуків (R3, R4) — лише в цій теці, не в `.claude/settings.json`.** незворотність: `reversible` —
  підключення до сесій буде окремим рішенням власника (це зміна налаштувань, R4 гейта).

  позначені як підроблені; гейт мусить їх відкидати.
