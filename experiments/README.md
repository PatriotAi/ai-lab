# experiments/ — експерименти

Кожен експеримент — окрема тека `experiments/<назва>/` з власним `README.md`
за шаблоном [`../templates/experiment.md`](../templates/experiment.md).

## Принцип
Маленька перевірена гіпотеза > велика неперевірена система. Спочатку наскрізний
зріз (vertical slice), потім розширення.

## Життєвий цикл
гіпотеза → дизайн → запуск → вимір → **лиши/прибери** → висновок у `docs/learnings.md`.

Те, що спрацювало й варте повтору, виносимо в `skills/` або `automations/`.
Те, що ні — лишаємо тут із чесним висновком (негативний результат теж знання).
