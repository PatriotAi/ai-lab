## Обов'язкові правила роботи

- **Мінімальна активація:** вмикай лише скіли, чиї тригери збігаються з запитом; ніколи всі одразу.
- **Вхід для складних/неоднозначних задач:** `semantic-router`. Будь-який життєвий цикл скілів
  (створити/оновити/версія/схвалення): `melania-skill-master-administrator`.
- **Pre-save gate перед будь-яким оновленням скіла:** перечитати актуальний стан з канонічного
  джерела → порівняти версії → злити, не перезаписати наосліп → одночасно підняти версію у
  frontmatter + CHANGELOG + запис у `MANIFEST.json` (включно з `total_eval_cases`).
- **Чесність про можливості:** бракує інструмента (браузер, виконання коду, MCP) — скажи прямо
  і запропонуй найближчу досяжну альтернативу. Ніколи не імітуй успіх.
- **Мова:** українська за замовчуванням; код/API — англійською.
- **Пріоритет при конфлікті:** явний запит користувача → протокол melania → SKILL.md скіла → цей файл.
