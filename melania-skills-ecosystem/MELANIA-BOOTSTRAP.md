## Обов'язкові правила роботи

- **Мінімальна активація:** вмикай лише скіли, чиї тригери збігаються з запитом; ніколи всі одразу.
- **Вхід для складних/неоднозначних задач:** `semantic-router`. Будь-який життєвий цикл скілів
  (створити/оновити/версія/схвалення): `melania-skill-master-administrator`.
- **Pre-save gate перед будь-яким оновленням скіла:** перечитати актуальний стан з канонічного
  джерела → порівняти версії → злити, не перезаписати наосліп → одночасно підняти версію у
  frontmatter + CHANGELOG + запис у `MANIFEST.json` (включно з `total_eval_cases`).
- **Чесність про можливості:** бракує інструмента (браузер, виконання коду, MCP) — скажи прямо
  і запропонуй найближчу досяжну альтернативу. Ніколи не імітуй успіх.
- **Мова:** українська за замовчуванням; код/API — англійською.
- **Стандарт диригента (вічний, для всіх рівнів і моделей):** `rlm-harness/references/conductor-standard.md` —
  верифікація ділом + canary, merge-not-replace, хірургічність, чесність звітів, економія,
  межі автоматики, успадкування суб-рівнями, все цінне → у напрацювання.
- **Закон не-старіння (Core Rule 11):** жодних назв моделей у правилах — лише класи/принципи;
  конкретика — тільки в датованому замінному model-snapshot (`multi-provider`); нове покоління
  моделей = заміна снапшота, не правил.
- **Актуальність усюди (anti-stale, Core Rule 12):** будь-яка згадка версії/лічильника/дати
  в будь-якому файлі = фактові на момент коміту; змінив щось — онови всі похідні згадки
  у ТОМУ Ж коміті. Дрейф «документ ≠ реальність» = дефект.
- **Джерело канону (Core Rule 13):** ієрархія істини — наданий пакет > диск > твій контекст;
  на кожен новий пакет спершу version-compare `MANIFEST.json`. **Монтування скілів буває
  застарілим у середині сесії** (нові з'являються, оновлення наявних — ні): помітив, що диск
  нижчий за відому версію — скажи вголос, що виконуєш старі інструкції, і попроси новий чат.
- **Пакування для скіл-стору:** завантажувач відхиляє крапкові шляхи (`.snapshots` є в кожному
  скілі) і вирізає `evals/` → пакуй через `maintain.py package`; source-істина тестів — репо/zip.
- **Пріоритет при конфлікті:** явний запит користувача → протокол melania → SKILL.md скіла → цей файл.
