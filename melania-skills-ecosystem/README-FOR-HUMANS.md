# 📦 Melania Skills Ecosystem — інструкція для людини

## Що це таке

Це **повна бібліотека з 28 скілів** — готових модулів-інструкцій, які навчають штучний інтелект конкретних умінь: керування скілами, валідація, оркестрація агентів, браузерна автоматизація, деплой, тестування, пам'ять між сесіями тощо. Бібліотека українською-першою, керується master-протоколом `melania`.

**Один пакет — будь-яка система.** Всередині лише відкриті формати (Markdown, JSON, Python), тому пакет працює з Claude, ChatGPT/Codex, Gemini та будь-яким майбутнім AI, що вміє читати файли.

## Найпростіший спосіб (будь-яка система)

1. Закинь **увесь цей пакет** (або zip-файл) у чат зі своїм AI.
2. Напиши: **«Прочитай README-FOR-AI.md і зроби як там написано»**.
3. AI сам розпізнає пакет, збереже скіли там, де його платформа зберігає постійні інструкції, і скаже тобі, що готово.

Далі просто працюй природно — AI сам викликатиме потрібний скіл.

## Покрокова інсталяція за платформами

### Claude (claude.ai)
1. Відкрий **Settings → Capabilities (Features) → Skills**.
2. Натисни **Upload skill** і завантаж скіли з теки `skills/` (кожну теку окремо, або `.skill`-файл якщо є).
3. Скіли з'являться у `/mnt/skills/user/` і будуть доступні **в усіх чатах** автоматично.
4. ⚠️ Особливість Claude: пакувальник `.skill` **не переносить теку `evals/`** — тест-кейси тримай у цьому пакеті (або в git) як source-копії.

### Claude Code / Cowork
Скопіюй теки скілів у `~/.claude/skills/` або в теку проєкту — вони підхопляться автоматично.

### ChatGPT / Codex (custom GPT або проєкт)
1. Створи проєкт або Custom GPT.
2. У **Knowledge / Files** завантаж `SKILL.md` потрібних скілів (+ їхні `references/`, якщо є).
3. В інструкції GPT додай рядок: *«Дій за правилами з завантажених SKILL.md; тригери й межі — у їхніх description»*.

### Gemini (Gems) та інші
Аналогічно: завантаж `SKILL.md` у постійний контекст (Gem knowledge / система інструкцій). Якщо платформа не має постійного сховища — тримай пакет у себе і прикріплюй потрібний `SKILL.md` на початку сесії.

## Що всередині

```
melania-skills-ecosystem/
├── README-FOR-AI.md        ← ІІ читає це першим (машинна інструкція)
├── README-FOR-HUMANS.md    ← ти зараз тут
├── MANIFEST.json           ← список усіх 28 скілів: версії, файли, SHA-256
├── INSTALL-PROMPT.txt      ← готова фраза-запуск для будь-якого AI
└── skills/                 ← 28 скілів, кожен самодостатній:
    └── <назва-скіла>/
        ├── SKILL.md        ← головний файл (інструкції + тригери + версія)
        ├── evals/          ← тест-кейси (134 усього по бібліотеці)
        ├── scripts/        ← захисні/службові скрипти (Python)
        └── references/     ← глибокі довідники (читаються за потреби)
```

## Ключові правила екосистеми (коротко)

- **Мінімальна активація:** AI вмикає лише потрібні скіли, не всі одразу.
- **Pre-save gate:** перед будь-яким оновленням скіла — перечитати актуальний стан, порівняти версії, злити (не перезаписати наосліп), підняти версію + CHANGELOG.
- **Чесність:** якщо на платформі бракує інструмента для якогось скіла — AI каже це прямо, не імітує успіх.
- **Evals = source-копії:** тримай цей пакет (чи git) як еталон тестів.
