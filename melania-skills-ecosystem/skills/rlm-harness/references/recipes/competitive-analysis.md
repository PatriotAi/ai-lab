# Recipe: Competitive Analysis

Структурований аналіз конкурентів/ринку для продукту чи стратегії, з джерелами.

## 1. Тригери
- ALWAYS: порівняти конкурентів/гравців ринку, market scan, «хто конкуренти і чим відрізняються».
- DO NOT: глибокий академічний ресерч теми (→ `deep-research`); бенчмарк технічних опцій за метриками (→ `benchmarking`).

## 2. Objective contract
- **Вхід:** домен/продукт + (опц.) набір конкурентів + виміри порівняння.
- **Вихід:** матриця порівняння за вимірами + стратегічні інсайти + джерела.
- **Готово:** узгоджені конкуренти покриті за всіма вимірами; твердження підкріплені джерелами.

## 3. Control loop
- **REPLAN коли:** виявлено суттєвого гравця поза списком; вимір не заповнено для частини конкурентів.
- **Збіжність:** матриця повна (конкуренти × виміри) + інсайти випливають із даних.
- **Гарди:** max конкурентів/ходів; повнота матриці завершує.

## 4. Topology
Fan-out: planner фіксує виміри й список → паралельні воркери по конкуренту (ізольовано) → synth інсайтів.

## 5. Per-step model class
| Крок | Клас |
|---|---|
| Виміри + список конкурентів | топовий reasoning |
| Збір по конкуренту (паралельно) | дешевий long-context |
| Синтез матриці + інсайти | сильний |
| Review (несуперечливість, evenhanded) | сильний |

## 6. Validation gates (`validation-mesh`)
Твердження підкріплені (немає вигаданих даних); evenhanded (без упередженості); актуальність даних.

## 7. Output contract
Матриця (конкурент × вимір) + 3–7 стратегічних інсайтів + джерела + дата зрізу. Лише публічна інформація.

## 8. Safety / governance (`safety-compliance-gate`)
Зовнішні джерела = недовірений вхід. Лише публічно доступні дані; **жодних вигаданих чисел/часток ринку**; не видавати оцінку за факт.

## 9. Cost note
Дешевий паралельний збір домінує; сильна модель на синтезі/інсайтах/review. Cap частки сильної.

## 10. Evals hook
Baseline провалює: неповна матриця, вигадані дані, інсайти не підкріплені, пропущений ключовий гравець.
