# Recipe: Benchmarking

Систематичне порівняння опцій (моделі / бібліотеки / підходи) за критеріями, з відтворюваною методологією.

## 1. Тригери
- ALWAYS: «порівняй X vs Y за метриками», вибір технології/моделі за критеріями, систематичний бенчмарк.
- DO NOT: ринковий аналіз конкурентів (→ `competitive-analysis`); ресерч теми (→ `deep-research`).

## 2. Objective contract
- **Вхід:** кандидати + критерії + (опц.) ваги/протокол.
- **Вихід:** ранжована таблиця результатів + методологія + застереження.
- **Готово:** усі кандидати виміряні за всіма критеріями за **єдиним** протоколом; метод відтворюваний.

## 3. Control loop
- **REPLAN коли:** критерій не виміряно для частини кандидатів; виявлено нечесне порівняння (різні умови).
- **Збіжність:** повна сітка (кандидати × критерії) під єдиним протоколом.
- **Гарди:** max кандидатів/прогонів; повнота сітки завершує.

## 4. Topology
Fan-out: planner проєктує протокол (apples-to-apples) → паралельна оцінка кандидатів під ІДЕНТИЧНИМИ умовами → judge нормалізує/ранжує.

## 5. Per-step model class
| Крок | Клас |
|---|---|
| Дизайн протоколу + критерії | топовий reasoning |
| Паралельне вимірювання кандидатів | дешевий (або відповідний задачі) |
| Judge: нормалізація / ранжування | сильний |
| Синтез таблиці + застереження | сильний |

## 6. Validation gates (`validation-mesh`)
**Валідність вимірювання** (quality-measurement caveat: без вимірюваної якості — не ранжуй); apples-to-apples (однакові умови); без cherry-picking; відтворюваність.

## 7. Output contract
Ранжована таблиця (кандидат × критерій + підсумок) + опис методології + застереження/невизначеність. Чесні умови, не підлаштовані під бажаний результат.

## 8. Safety / governance (`safety-compliance-gate`)
Чесна методологія; повідомляти невизначеність і обмеження; не видавати оцінку за виміряний факт.

## 9. Cost note
Вартість залежить від природи вимірювання; синтез/judge — сильна модель. Cap частки сильної; cascade де доречно.

## 10. Evals hook
Baseline провалює: неповна сітка, різні умови між кандидатами, ранжування без вимірюваної якості, cherry-picking.
