# Recipe: Red-Team (DEFENSIVE-ONLY)

Змагальне тестування системи/AI/промпту на слабкі місця заради **загартування**. Знайти, щоб полагодити — не озброїти.

## 1. Тригери
- ALWAYS: змагальна перевірка стійкості (AI-промпт, агент, пайплайн, авторизація); «red-team», «знайди слабкі місця для захисту».
- DO NOT: створення робочого атак-інструментарію/малварі/jailbreak-у для зловживання (→ ВІДМОВА, `safety-compliance-gate`).

## 2. Objective contract
- **Вхід:** ціль + межі дозволеного (scope) + критерій успіху атаки.
- **Вихід:** каталог слабких місць (відтворюваних) + **мітигації/загартування** на кожне.
- **Готово:** систематичне змагальне покриття (категорії атак) + кожне знайдене має мітигацію.

## 3. Control loop
- **REPLAN коли:** ціла категорія атак ще не випробувана; знайдене потребує варіацій для підтвердження.
- **Збіжність:** атак-дерево пройдене + знахідки відтворені й триаговані.
- **Гарди:** max спроб/глибина; рубрика severity.

## 4. Topology
Fan-out: planner будує атак-дерево → паралельні воркери з **різноманітними** пробами (різні налаштування для покриття) → judge відтворюваності.

## 5. Per-step model class
| Крок | Клас |
|---|---|
| Атак-дерево / план | топовий reasoning |
| Різноманітні проби (паралельно) | дешеві, варіативні налаштування |
| Judge: відтворюваність + severity | сильний |
| Синтез каталогу + мітигації | сильний |

## 6. Validation gates (`validation-mesh`)
Кожне слабке місце відтворюване (не випадковість); severity; запропонована мітигація справді закриває вектор.

## 7. Output contract
Каталог: вектор · відтворення · severity · **мітигація/загартування**; зведення постави стійкості. Без готового зловмисного інструментарію.

## 8. Safety / governance (`safety-compliance-gate`) — КРИТИЧНО
**Defensive-only:** мета — загартування, продукт — слабкі місця + фікси, не атак-тулкіт. У межах дозволеного scope. Прохання озброїти → відмова.

## 9. Cost note
Дешеві паралельні проби домінують; сильна модель на плані/judge/синтезі. Cap частки сильної.

## 10. Evals hook
Baseline провалює: несистемне покриття, невідтворені «знахідки», брак мітигацій, АБО продукує зловмисний інструмент (має відмовити).
