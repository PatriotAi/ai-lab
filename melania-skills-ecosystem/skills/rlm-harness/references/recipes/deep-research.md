# Recipe: Deep Research

Цитований ресерч по багатьох джерелах із синтезом. Конфігурує контрол-луп RLM Harness; механіку делегує.

## 1. Тригери
- ALWAYS: глибоке дослідження питання по багатьох джерелах із цитованим висновком; «досліди ґрунтовно», «звіт із джерелами».
- DO NOT: один факт / один пошук (→ просто web_search); резюме одного документа.

## 2. Objective contract
- **Вхід:** дослідницьке питання (+ опц. обсяг/глибина, мова).
- **Вихід:** структурований звіт, де КОЖНЕ твердження атрибутоване джерелу; список відкритих питань.
- **Готово:** усі під-питання покриті; ключові твердження мають джерело; основні суперечності між джерелами розв'язані або позначені.

## 3. Control loop (Plan-Execute-Verify-Replan)
- **REPLAN коли:** виявлено прогалину покриття під-питання; джерела суперечать і конфлікт не закритий; джерело низької довіри без підтвердження.
- **Збіжність:** усі під-питання відповіді + немає неопрацьованих великих конфліктів джерел.
- **Гарди:** max глибина під-питань / max джерел / max ходів / timeout.

## 4. Topology (делегує `workflow-orchestration`)
Fan-out subagents: planner розбиває на під-питання → паралельні воркери-збирачі (ізольований контекст) → judge → synth. Назад — typed-context, не сира історія.

## 5. Per-step model class (за `model-fit-policy.md`)
| Крок | Клас |
|---|---|
| План під-питань (DAG) | топовий reasoning |
| Паралельний збір/екстракція | швидкий дешевий long-context |
| Credibility judge (довіра/конфлікти) | сильний |
| Синтез чернетки | сильний |
| Review (атрибуція/несуперечливість) | сильний |

## 6. Validation gates (`validation-mesh`)
Довіра джерела (офіційне/первинне > агрегатор); атрибуція твердження→джерело; детекція суперечностей; немає вигаданих фактів/цитат.

## 7. Output contract
Цитований звіт (твердження + джерело), «що невідомо/потребує підтвердження», список джерел. Без дослівного відтворення (copyright: переказ, не копія).

## 8. Safety / governance (`safety-compliance-gate`)
Веб = **недовірений вхід** (можливі ін'єкції в контент). Copyright: переказ, цитати мінімальні. **Жодних вигаданих джерел/цитат.**

## 9. Cost note
Дешевий паралельний збір домінує; сильна модель лише judge/synth/review. Cap частки сильної ~14–26%; cascade на провалі гейта довіри.

## 10. Evals hook
Baseline (один дешевий виклик без синтезу/гейтів) **провалює**: неповне покриття, відсутня атрибуція, непомічені конфлікти джерел.
