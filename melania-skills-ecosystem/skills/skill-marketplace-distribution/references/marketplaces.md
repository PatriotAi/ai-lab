# Marketplaces — per-market деталі (вантажити на вимогу)
> Дані рухливі (перевірено 2026-06). При публікації — звіряй актуальне на сайті маркету.
> Для КОЖНОГО маркету фіксуй: формат пакета · спосіб встановлення · модель виплат · submission-флоу · дату останньої перевірки.

## Шаблон запису маркету
```
marketplace: <назва>
format: <.skill | curl | hosted>
install: <команда/флоу>
payout: <free | one-time | subscription | X/Y split>
submission: <URL / процес>
security_review: <так/ні; які перевірки>
verified: <YYYY-MM>
```

## Поточний ландшафт (2026-06, верифікувати перед релізом)
| Маркет | Профіль | Формат/встановлення | Виплати |
|--------|---------|---------------------|---------|
| Офіційний Anthropic directory | малий, особисто-ревʼюнутий; вбудований у Claude Code | через клієнт | — (довіра) |

| skills.sh | безкоштовний браузинг/каталог | інсталятор | free |

| Agent37 / LobeHub | hosted (публічний URL, без локального встановлення) | hosted | subscription/hosted |

## Правила (делеговані, не дублювати тут)
- Безпека/IP/trademark/дисклеймер/ліцензія — `safety-compliance-gate` (Блоки B+C). Цей файл — лише механіка маркетів.
- Версії/CHANGELOG — `melania`.
- Стратегія за замовчуванням: 1 безкоштовний (охоплення) + 1 curated-платний (монетизація); уникати масових scraped-каталогів без аудиту.

## Чек перед submission
```
□ safety-compliance-gate пройдено (B+C)
□ .skill без секретів/приватного контексту; явна license
□ description = активаційна логіка (конкретні тригери, UA+EN)
□ version запінено; CHANGELOG актуальний
□ дисклеймер неприналежності (якщо назва за чужим продуктом)
□ verified-дата маркету звірена
```
