# Skill Marketplace Distribution — v0.1.1
> Українською-перша: рішення/приклади — українською; код/ідентифікатори — англійською.
> ⚖️ Безпека та комплаєнс — `safety-compliance-gate` (ОБОВ'ЯЗКОВО перед пакуванням/публікацією/комерціалізацією).

## 🛡️ Протокол Збереження Перед Оновленням (ОБОВ'ЯЗКОВО)
Обов'язковий перед БУДЬ-ЯКОЮ зміною цього скіла. **Канонічне джерело (не дублювати тут):** `melania` — секції «🛡️ Протокол Збереження Перед Оновленням» + «Update Workflow» + «Core Rule 10 — Re-Read Before Update».

Стисло: re-read диску → порівняти версії (диск новіший → диск база) → integrity-diff → validation-mesh → safety-compliance-gate (перед пакуванням/публікацією) → backup/snapshot → merge-not-replace → bump+CHANGELOG → показати diff і чекати явного схвалення MA (Закон II).


## Core Rule
**Публікуй лише ПІСЛЯ проходження `safety-compliance-gate` (Блоки B+C).** Маркетплейс обирай
за ціллю (безкоштовне охоплення vs перевірений платний). Для споживачів — **пінь версію**.
Ніколи не публікуй секрети/приватний контекст. Цей скіл — про КУДИ і ЯК публікувати; безпеку/IP
делегує гейту, авторинг — `skill-creation-guide`, версії — `melania`.

## Decision Gate — чому окремий скіл
Додає те, чого немає в жодному наявному: (1) **карту маркетплейсів** + вибір за ціллю,
(2) **механіку пакування** (.skill, curl-інсталятор, що включати/виключати), (3) **монетизацію**
(моделі, виплати), (4) **discovery-оптимізацію опису**. Безпеку/IP (`safety-compliance-gate`),
авторинг (`skill-creation-guide`), версії (`melania`) — делегує, не дублює.

## 1. Карта маркетплейсів (2026) — обирай за ціллю
| Маркет | Профіль | Коли |
|--------|---------|------|
| Офіційний Anthropic directory (у Claude Code) | малий, перевірений | максимальна довіра |
| ClaudeSkills.info | безкоштовний, community-vetted, велике охоплення | вільне поширення |
| skills.sh | безкоштовний браузинг | вільне поширення |
| Agensi | curated, 8-точковий security-scan, виплати **80/20**, curl-install | перевірений платний |
| Agent37 / LobeHub | hosted (публічний URL, без локального встановлення) | hosted-доступ/SaaS |

**Стратегія за замовчуванням:** один безкоштовний (охоплення) + один curated-платний (монетизація).
Уникай масових scraped-каталогів без аудиту.

## 2. Пакування
- **.skill bundle** = `SKILL.md` + `references/` + `evals/` + (опц.) `scripts/`. Без секретів/приватних даних.
- **curl one-liner** — інсталятор однією командою (формат маркету).
- **Обов'язково:** явна `license:`; дисклеймер неприналежності, якщо назва за чужим продуктом (гейт B2).
- **Виключити:** ключі, токени, внутрішні шляхи, приватний контекст, чужий код без рев'ю (гейт C).

## 3. Опис = активаційна логіка (load-bearing)
Claude не «гортає» маркет — активує скіл за семантичною релевантністю опису. Тому `description`:
- конкретні тригери (коли саме вмикати), не «допомагає з X»;
- українська-перша + ключові англ. тригери для крос-платформного discovery;
- ALWAYS/Also/DO NOT секції. Поганий опис = скіл невидимий (і не продається).

## 4. Version-pinning для споживачів
- Semver; рекомендуй споживачам **пінити версію** (не авто-апдейт неперевіреного).
- Дисциплінований CHANGELOG (механіка версій — `melania`).
- Конвергенція форматів 2026 (Codex/Cursor) — портативність не безшовна; познач у `compatibility:` що перевірено.

## 5. Монетизація (підвищена планка — гейт B4)
- Моделі: безкоштовно · one-time купівля · hosted-підписка. Agensi — **80/20** на користь автора.
- Покупець платить за **надійність/ясність рішення**, не за «розумність». Сигнал ціни: ризик / вартість / обсяг.
- Продаж скіла, названого за чужою маркою → рев'ю-перед-релізом (гейт B4). Цей скіл — не юридична порада.

## 6. Publish workflow (петля, гейтована)
```
author (skill-creation-guide) → validate (validation-mesh)
  → secure/IP (safety-compliance-gate Блоки B+C)  ← НЕ обійти
  → package (.skill + curl) → publish (обраний маркет) → pin (semver) → monitor
```

## Behavior
| Ситуація | ✓ Дія | ✗ Ніколи |
|----------|-------|----------|
| Готовий публікувати скіл | спершу прожени safety-compliance-gate | не публікуй до проходження гейта |
| Вибір маркетплейсу | за ціллю (охоплення vs платний) | не лий у всі підряд / scraped-каталоги |
| Пакування | .skill без секретів, з ліцензією | не включай ключі/приватний контекст |
| Монетизація скіла за чужою маркою | рев'ю-перед-релізом (гейт B4) | не продавай голу чужу назву як бренд |
| Споживачу | рекомендуй пін версії | не пхай авто-апдейт неперевіреного |
| Слабкий discovery | переписати опис як активаційну логіку | не лишай «допомагає з X» |
