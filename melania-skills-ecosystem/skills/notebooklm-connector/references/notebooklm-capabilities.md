## Типи джерел

| Тип | Деталі |
|---|---|
| Веб-сторінка | Публічні URL, без paywall |
| PDF | Текстові + скановані (OCR), підтримує зображення та графіки (multimodal) |
| Google Docs / Slides / Sheets | Публічний sharing обов'язковий, автосинхронізація |

## Studio — Всі функції генерації

### Audio Overview (оновлено 2025)
- Два AI-ведучих у форматі подкасту
- **Нові формати:** Brief (короткий), Deep Dive (детальний), Critique (критичний), Debate (дискусія)
- **Interactive Mode:** перервати і задати питання під час прослуховування
- Customization: фокус, аудиторія, стиль, довжина
- Мова аудіо: переважно англійська; текстові джерела — будь-яка

### Video Overview (новинка 2025)
- Наративний відеопрезентація з візуалізацією та голосом
- Генерується довше за Audio (~5-10 хв)

### Briefing Doc
- Executive Summary, ключові теми, факти, відкриті питання
- MCP: `notebooklm_generate_briefing`

### Study Guide
- Ключові поняття, питання для перевірки, есе-питання

### FAQ
- Питання-відповіді на основі всіх джерел

### Timeline
- Хронологія подій; для новин, історії, проектів

### Table of Contents
- Структурований зміст; для довгих документів

### Mind Map (новинка 2025)
- Інтерактивна карта концепцій і зв'язків
- Навігація по темах Notebook

### Slide Deck (новинка 2025)
- Готова презентація з джерел
- Watermark на Free плані, без — на Ultra

### Infographic (новинка 2025)
- Візуальна інфографіка на основі ключових даних

### Flashcards & Quizzes (новинка вересень 2025)
- Картки для запам'ятовування
- Тести з миттєвим зворотним зв'язком

### Deep Research (новинка листопад 2025)
- Агентний режим: NotebookLM активно шукає нову інформацію поза джерелами
- Перехід від RAG до agentic researcher

## Chat — розширені можливості (2025-2026)

- **1 млн токенів** контекстного вікна (8x більше ніж раніше)
- **6x довша** пам'ять розмови
- **Goals/Personas:** налаштування до 10,000 символів — роль, тон, стиль, формат
  - Приклад: "Ти суворий Product Manager. Відповідай тільки через Decision Memo формат."
- **Output language selector:** обирай мову відповіді незалежно від мови джерел
- **Inline citations** з переходом до оригіналу
- **Save to notes** прямо з Chat

## Найефективніші Chat-запити

```
Синтез:     "Синтезуй ключові аргументи всіх джерел щодо [ТЕМИ]"
Порівняння: "Як [А] і [Б] по-різному трактують [КОНЦЕПЦІЮ]?"
Факти:      "Яка конкретна статистика щодо [X] у джерелах?"
Критика:    "Які суперечності або слабкі місця є в джерелах?"
Прогалини:  "Які важливі аспекти [ТЕМИ] НЕ охоплені?"
Persona:    Встановити Goal → "Ти [РОЛЬ]. Відповідай у форматі [ФОРМАТ]."
```

## Troubleshooting

| Проблема | Рішення |
|---|---|
| URL не додається | Paywall → Copied text |
| Низька якість Audio | Додати 3+ різних джерел + використати Customize |
| Chat неточний | Видалити нерелевантні джерела + встановити Goal |
| PDF без тексту | Скан → OCR-сервіс перед завантаженням |
| YouTube без транскрипту | Завантажити субтитри вручну |
| Slide Deck з watermark | Потрібен Plus / Ultra план |
