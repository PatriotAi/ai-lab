# Citation & Source Workflow

## Citation Extraction

NotebookLM Chat дає відповіді з посиланнями на джерела. Витягуй їх:

```
При запиті в Chat:
1. Постав питання
2. Відповідь містить inline-цитати [1] [2] [3]
3. Клік на цитату → підсвічує точне місце в джерелі
4. Для експорту: копіюй відповідь + список джерел знизу

Структура цитованої відповіді:
  Твердження [1]. Інше твердження [2][3].

  Sources:
  [1] Document A, page 5
  [2] URL source, section "Methods"
  [3] PDF B, paragraph 12
```

## Source Comparison

```
Порівняння кількох джерел на одну тему:

Запит у Chat:
"Порівняй що джерело A і джерело B кажуть про X.
 Де вони згодні? Де суперечать?"

NotebookLM:
- Знайде відповідні місця в обох
- Виділить згоду/розбіжності
- Дасть цитати з кожного

Корисно для: literature review, fact-checking, синтез думок.
```

---

## Multi-Source Synthesis

```
Робочий процес для дослідження:

1. Додай 5-10 джерел (статті, PDF, URL)
2. Згенеруй Briefing Doc → загальний огляд
3. Згенеруй Study Guide → ключові концепції + питання
4. Chat для конкретики: "Які методи використано в усіх джерелах?"
5. Audio Overview → подкаст-формат для засвоєння
6. Mind Map → візуальна структура зв'язків

Кожен output підсвічує різні аспекти тих самих джерел.
```

---

## Source Quality Signals

```
Перед додаванням джерела оцінюй:
✓ Релевантність темі notebook
✓ Якість (peer-reviewed > blog)
✓ Свіжість (для змінних тем)
✓ Унікальність (не дубль наявного)

Забагато низькоякісних джерел → розмиває якість усіх outputs.
Краще 5 якісних ніж 50 випадкових.
```

---

## Notebook Organization

```
Один notebook = одна тема/проект.

✗ Все в одному notebook (50 джерел про різне)
✓ Окремі notebooks: "Проект A", "Дослідження B"

NotebookLM індексує в межах notebook → чистіша тема = точніші відповіді.
```

## Export Strategies

```
| Output | Найкраще для | Експорт |
|--------|-------------|---------|
| Briefing Doc | швидкий огляд | копіюй текст |
| Audio Overview | засвоєння на ходу | завантаж аудіо |
| Study Guide | підготовка/навчання | копіюй Q&A |
| Mind Map | презентація структури | скриншот/експорт |
| FAQ | документація | копіюй |
| Chat answers | конкретні факти | копіюй з цитатами |
```
