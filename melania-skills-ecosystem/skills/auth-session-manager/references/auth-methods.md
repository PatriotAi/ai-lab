# Auth & Session Manager — детальні методи
> Читається лише за потреби. SKILL.md тримає короткий протокол; деталі — тут.

## 1. Видобування cookie — покроково

### Десктоп (Chrome/Edge/Firefox)
1. Встанови розширення **Cookie-Editor**.
2. Відкрий цільовий сайт, увійди вручну.
3. Cookie-Editor → **Export** → **JSON**.
4. Збережи як масив обʼєктів `{name, value, domain, path, expires, httpOnly, secure}`.
Альтернатива: DevTools (F12) → Application → Cookies → скопіювати потрібні.

### Android (без root)
- **Варіант А — Kiwi/Yandex Browser:** підтримують десктопні розширення → встанови Cookie-Editor → як на десктопі.
- **Варіант Б — Remote Debugging:** на телефоні увімкни USB-debugging; на ПК відкрий `chrome://inspect`, інспектуй вкладку, експортуй cookie через DevTools.
- Зберегти JSON у менеджер секретів (зашифровано, Pattern 4).

## 2. OAuth React-артефакт — схема
1. Артефакт показує кнопку «Увійти через {сервіс}».
2. Відкриває OAuth-URL (client_id, redirect_uri, scope, state).
3. Користувач дає згоду → редірект із `code`.
4. Артефакт обмінює `code` на токен (через бекенд/проксі — НЕ зашивати client_secret у клієнт).
5. Токен → шифрування (Pattern 4) → зберігання.
Правило: `state` перевіряти завжди (CSRF); `client_secret` ніколи не в клієнтському коді.

## 3. PBKDF2 + AES-GCM — деталі
- **PBKDF2:** SHA-256, ≥100 000 ітерацій, випадкова сіль 16 байт на кожен секрет.
- **AES-GCM:** 256-біт ключ, випадковий IV 12 байт на кожне шифрування (ніколи не повторювати IV з тим самим ключем).
- Зберігати: `{salt, iv, ct}`. НЕ зберігати: ключ, пароль, plaintext.
- Розшифрування: ввід пароля користувачем → derive key → decrypt. Якщо пароль втрачено — секрет невідновний (за задумом).

## 4. Каскад — детальні умови падіння
| Метод | Падаємо далі коли |
|-------|-------------------|
| inject_cookies | немає збережених cookie АБО сесія `!healthy` після інʼєкції |
| browserbase_authenticate | Browserbase недоступний АБО логін не завершився |
| OAuth-артефакт | сервіс не підтримує OAuth АБО згода відхилена |
| guided manual | завжди останній — даємо інструкцію користувачу |

## 5. Чого ніколи не робити
- Не логувати значення cookie/токенів (навіть частково, навіть для дебагу).
- Не зашивати ключі/паролі/секрети у код, JSON, артефакт.
- Не зберігати пароль шифрування поряд із зашифрованими даними.
- Не передавати секрети стороннім сервісам без явної згоди користувача.
- Не повторювати IV з тим самим ключем AES-GCM.
