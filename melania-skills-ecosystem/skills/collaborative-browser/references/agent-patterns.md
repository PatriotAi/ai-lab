# Collaborative Browser — Advanced Agent Patterns

## Autonomous Research Loop

```
Глибокий автономний ресерч:

ЦІЛЬ: "Дослідь тему X вичерпно"

Loop (max 20 сторінок, max depth 5):
  1. search(X) → кандидати
  2. rank за релевантністю (агент оцінює сніпети)
  3. fetch top-3 паралельно
  4. extract: ключові факти + нові підтеми + джерела
  5. IF нові підтеми AND depth < 5:
       додай у чергу дослідження
  6. synthesize накопичені факти
  7. validate через validation-mesh
  8. IF покриття достатнє → STOP, звіт
     ELSE → наступна ітерація

Вихід: структурований звіт з джерелами + рівнем впевненості.
```

## Multi-Tab Coordination

```
Агент керує кількома вкладками паралельно:

Tab 1: основне джерело (читання)
Tab 2: перехресна перевірка факту
Tab 3: пошук додаткового контексту

Координація через спільний стан (BroadcastChannel):
- кожна вкладка пише знахідки у спільний стор
- агент синтезує з усіх вкладок
- уникає дублювання роботи
```

## AI Code Builder Pattern

```
Генерація mini-app у браузері:

1. Користувач описує застосунок
2. Агент генерує single-file HTML/JS (через Anthropic API)
3. Рендерить у iframe (sandbox)
4. Користувач тестує наживо
5. Ітерація: "додай X" → агент патчить (surgical, не переписує)
6. Експорт: завантаж HTML / деплой

Координація з surgical-code-refactoring для безпечних правок.
```

## Screenshot Analysis

```
Агент аналізує візуальний стан сторінки:

1. Зроби screenshot поточної сторінки
2. Передай Claude (vision) → "що на екрані?"
3. Агент розуміє: кнопки, форми, контент, layout
4. Пропонує дії: "клікни X", "заповни форму Y"
5. Виконує → новий screenshot → перевірка результату

Корисно для: складних UI, динамічного контенту, верифікації дій.
```

## Secrets Manager Integration

```
Безпечне зберігання облікових даних (AES-GCM):

- cookie/токени шифруються локально
- ключ з master-password (PBKDF2)
- координація з auth-session-manager для session health
- ніколи не логуй секрети у відкритому вигляді

Деталі AES-GCM: auth-session-manager/references/oauth-flows.md
```
