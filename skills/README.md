# skills/ — каталог навичок

Тут лежить **версіонований source** навичок лабораторії. Навичка (skill) — це
інструкція-автоматизація для Claude Code: коли і як виконати повторюване завдання.

## Як це працює
- **Source (тут):** `skills/<name>/SKILL.md` — під git, рев'ю, історією.
- **Активна навичка:** Claude Code підхоплює навички з `.claude/skills/<name>/SKILL.md`
  (проєктні) або `~/.claude/skills/` (глобальні). Активуємо потрібні з каталогу.

## Формат
Кожна навичка = тека з `SKILL.md`. Шаблон — [`../templates/skill.md`](../templates/skill.md).
Ключове — поле `description`: **чіткий тригер**, коли навичку застосовувати.

## Активні навички
- `skill-new` — фабрика навичок: `.claude/skills/skill-new/SKILL.md`. Виклик: `/skill-new`.
- `translate-uaen` — двомовна локалізація UA⇄EN з глосарієм. Виклик: `/translate-uaen`.
- `experiment` — запуск і ведення експерименту за методологією. Виклик: `/experiment`.
